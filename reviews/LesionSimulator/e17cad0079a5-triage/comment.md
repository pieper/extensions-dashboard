Suggestions for a later update:

- [`MSLesionSimulator/MSLesionSimulator.py:986-995`](https://github.com/CSIM-Toolkits/Slicer-LesionSimulatorExtension/blob/e17cad0079a5d01f2540df6439eb91cecbbfef35/MSLesionSimulator/MSLesionSimulator.py#L986-L995): `urllib.urlretrieve` does not exist in Python 3 (it is urllib.request.urlretrieve), and slicer.kitware.com/midas3 is retired, so this test raises AttributeError or fails the download. Because MSLesionSimulator/CMakeLists.txt:38 registers it via slicer_add_python_unittest, the extension's own test suite fails in CI and gives no real coverage. Use slicer.util.downloadFile / urllib.request.urlretrieve with a current URL, or use slicer.util.loadVolume on a Slicer sample data node.
- [`MSLesionSimulator/MSLesionSimulator.py:828`](https://github.com/CSIM-Toolkits/Slicer-LesionSimulatorExtension/blob/e17cad0079a5d01f2540df6439eb91cecbbfef35/MSLesionSimulator/MSLesionSimulator.py#L828): onApplyButton calls logic.run directly, and every step (BrainsFit registration, GenerateMask, FilterMask, DeformImage, MSLongitudinalExams) uses wait_for_completion=True. A full run with several modalities and follow-ups can take many minutes, during which Slicer's UI is frozen with no progress bar or cancel option. Run the pipeline in a background thread (e.g. ScriptedLoadableModuleLogic with a CLI status observer) or use slicer.cli.run with a completion callback and progress reporting.
- [`MSLesionSimulator/MSLesionSimulator.py:351-355`](https://github.com/CSIM-Toolkits/Slicer-LesionSimulatorExtension/blob/e17cad0079a5d01f2540df6439eb91cecbbfef35/MSLesionSimulator/MSLesionSimulator.py#L351-L355): The expression yields a vtkMRMLScalarVolumeNode (or None), not a bool, and is assigned to the Qt `enabled` property. Depending on the PyQt binding this either raises a TypeError during setup() or relies on implicit truthiness conversion; the intended `bool(...)` is missing. Wrap the expression in bool(...).
- [`FilterMask/Testing/Cxx/CMakeLists.txt:16-21`](https://github.com/CSIM-Toolkits/Slicer-LesionSimulatorExtension/blob/e17cad0079a5d01f2540df6439eb91cecbbfef35/FilterMask/Testing/Cxx/CMakeLists.txt#L16-L21): The same boilerplate test is used for FilterMask, GenerateMask, DeformImage and MSLongitudinalExams: it passes `--sigma 2.5` and a CT head volume, but FilterMask requires inputMask/cutFactor, GenerateMask requires lesionLoad/databasePath, and MSLongitudinalExams requires lesionLabel/outputFolder. These tests cannot pass and provide no verification of the modules. Write per-module tests with the actual required arguments and baseline data, or remove the placeholder tests.
- [`GenerateMask/GenerateMask.cxx:66-69`](https://github.com/CSIM-Toolkits/Slicer-LesionSimulatorExtension/blob/e17cad0079a5d01f2540df6439eb91cecbbfef35/GenerateMask/GenerateMask.cxx#L66-L69): The directories contain 951, 945, 139, 118 and 76 files respectively, but the hard-coded counts are one lower, so `rand() % infoArray[size]` never reaches the highest-numbered label file. The counts are also hard-coded rather than derived from the directory, so any database update silently breaks the mapping. Count the files at runtime (or fix the constants to match) and derive the arrays from the database directory.
- [`MSLongitudinalExams/MSLongitudinalExams.cxx:351`](https://github.com/CSIM-Toolkits/Slicer-LesionSimulatorExtension/blob/e17cad0079a5d01f2540df6439eb91cecbbfef35/MSLongitudinalExams/MSLongitudinalExams.cxx#L351): Output names are fixed (volT1_TimePoint_1.nii.gz, ...) in the user-selected folder, so a second run silently overwrites previous results. If outputFolder is left empty (the XML <directory> parameter has no default), files are written relative to the process working directory. Create a timestamped subfolder or refuse to overwrite existing files, and validate that outputFolder is non-empty.
- [`docs/index.md:18-20`](https://github.com/CSIM-Toolkits/Slicer-LesionSimulatorExtension/blob/e17cad0079a5d01f2540df6439eb91cecbbfef35/docs/index.md#L18-L20): The documentation motivates the tool with clinical diagnosis and therapy decisions but never states that simulated images are synthetic research data and must not be used for diagnosis or treatment decisions. Users could mistake simulated lesions for real findings. Add an explicit statement that outputs are synthetic research data, not for clinical diagnosis or treatment planning.
- [`MSLesionSimulator/MSLesionSimulator.py:239-243`](https://github.com/CSIM-Toolkits/Slicer-LesionSimulatorExtension/blob/e17cad0079a5d01f2540df6439eb91cecbbfef35/MSLesionSimulator/MSLesionSimulator.py#L239-L243): QSpinBox is integer-valued, so setSingleStep(0.1) truncates to 0 or 1 depending on the Qt version. The user may be unable to step the value as intended. This is an ordinary UI bug, not a safety issue. Use a QDoubleSpinBox or an integer step of 1.
