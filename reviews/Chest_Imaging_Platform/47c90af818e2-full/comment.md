- [`Scripted/CIP_/CIP/logic/geometry_topology_data.py:179-181`](https://github.com/acil-bwh/SlicerCIP/blob/47c90af818e2ef4bdd4420d9a7b2fec7307afe23/Scripted/CIP_/CIP/logic/geometry_topology_data.py#L179-L181): In `GeometryTopologyData.to_xml_file`, `self.to_xml()` returns a `str`, which is then written to a file opened in binary mode `"w+b"`. In Python 3 (Slicer 5), `f.write(s)` with a `str` on a binary file raises `TypeError: a bytes-like object is required, not 'str'`. This breaks saving fiducial/seed XML files in `CIP_LesionModel` and `CIP_PointsLabelling`. Similarly, `np.int`, `np.float`, and `np.bool` are used in `Util.py`, `geometry_topology_data.py`, and `FeatureExtractionLib`, which were removed in NumPy 1.24+. Open the XML file in text mode (`open(xml_file_path, "w")` and `open(xml_file_path, "r")`) or encode the string to UTF-8 bytes, and replace deprecated `np.int`/`np.float`/`np.bool` aliases with `int`/`float`/`bool`.
- [`Scripted/attic/CIP_GetImage/CIP_GetImage_Resources/WinSCP.ini:3-4`](https://github.com/acil-bwh/SlicerCIP/blob/47c90af818e2ef4bdd4420d9a7b2fec7307afe23/Scripted/attic/CIP_GetImage/CIP_GetImage_Resources/WinSCP.ini#L3-L4): The repository commits two ~10 MB Windows executables (`WinSCP.exe` and `WinSCP.com`) in both `Scripted/CIP_/CIP/ui/Resources/SSH/` and `Scripted/attic/CIP_GetImage/CIP_GetImage_Resources/`, along with an internal institutional SSH host key in `WinSCP.ini`. While neither `CIP_GetImage` nor the `SSH` resources are installed by the active CMake configuration, committing third-party Windows executables and internal server host keys into the source repository bloats the checkout and bundles unverified binaries. Remove the unused `WinSCP.exe`/`WinSCP.com`/`WinSCP.ini` files and the `Scripted/attic` folder from the repository.
- [`Scripted/CIP_/CIP/logic/Util.py:97-101`](https://github.com/acil-bwh/SlicerCIP/blob/47c90af818e2ef4bdd4420d9a7b2fec7307afe23/Scripted/CIP_/CIP/logic/Util.py#L97-L101): `Util.create_directory` and `CIP_PointsLabellingWidget.saveResultsCurrentNode` explicitly set `0o777` (world-writable) permissions on newly created directories. On multi-user systems, this allows other local users to modify or replace files in those directories. Use default directory permissions (`os.makedirs(path, exist_ok=True)`) without `os.chmod(..., 0o777)`.
- [`Scripted/CIP_LesionModel/FeatureExtractionLib/FirstOrderStatistics.py:51-52`](https://github.com/acil-bwh/SlicerCIP/blob/47c90af818e2ef4bdd4420d9a7b2fec7307afe23/Scripted/CIP_LesionModel/FeatureExtractionLib/FirstOrderStatistics.py#L51-L52): FeatureExtractionLogic.py lines 237–243 supplies histogram frequencies, not normalized probabilities. Consequently, even a constant region with more than one voxel yields a positive value instead of zero entropy, and the result changes with region size; exported quantitative features are misleading. Normalize nonzero histogram counts and calculate -sum(p*log2(p)); add numerical tests for constant and known distributions.
- [`Scripted/CIP_/CMakeLists.txt:28`](https://github.com/acil-bwh/SlicerCIP/blob/47c90af818e2ef4bdd4420d9a7b2fec7307afe23/Scripted/CIP_/CMakeLists.txt#L28): `Scripted/CIP_/CIP/logic/Colors.py` reads `chest_region_colors.ctbl` and `chest_type_colors.ctbl` from `SlicerUtil.CIP_RESOURCES_DIR`, and `SlicerUtil.getIcon("upload.png")` references `upload.png`, but `Scripted/CIP_/CMakeLists.txt` only installs `CIP/ui/Resources/StructuresColorMap.ctbl` and omits `chest_region_colors.ctbl`, `chest_type_colors.ctbl`, and `upload.png` from `MODULE_PYTHON_RESOURCES`. Calling `Colors.ChestRegions()` or `Colors.ChestTypes()` in an installed package will raise `FileNotFoundError` (and in Python 3 `Colors.__readColorMapFile__` opens the file in binary mode `"r+b"` and splits on `" "` str, which would also raise `TypeError`).
