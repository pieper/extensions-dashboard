- [`BoneThicknessMapping/BoneThicknessMapping.py:912`](https://github.com/Auditory-Biophysics-Lab/SlicerBoneThicknessMappingExtension/blob/56c40be2e11af6534b84203f7977e2c6d0c9c8ad/BoneThicknessMapping/BoneThicknessMapping.py#L912): build_color_table_nodes prints the air-cell range to the Python console on every run. - [`README.md:10`](https://github.com/Auditory-Biophysics-Lab/SlicerBoneThicknessMappingExtension/blob/56c40be2e11af6534b84203f7977e2c6d0c9c8ad/README.md#L10): The module outputs thickness maps from CT data that users may interpret clinically (for example, for surgical planning). Neither the README nor the module help text states that the output is research-only or not for diagnosis. The help text is also stamped with a 2020 version. Add a research-use disclaimer to the README and module help text, and update the version stamp.
- [`BoneThicknessMapping/BoneThicknessMapping.py:686-688`](https://github.com/Auditory-Biophysics-Lab/SlicerBoneThicknessMappingExtension/blob/56c40be2e11af6534b84203f7977e2c6d0c9c8ad/BoneThicknessMapping/BoneThicknessMapping.py#L686-L688): The code calls effect.self().onApply(), which is an internal Python method of the segment editor effects, not a public API. It may break in future Slicer versions without warning. Use the public segment-editor parameter and apply path, or document the supported Slicer versions and test against them.
- [`BoneThicknessMapping/BoneThicknessMapping.py:667-668`](https://github.com/Auditory-Biophysics-Lab/SlicerBoneThicknessMappingExtension/blob/56c40be2e11af6534b84203f7977e2c6d0c9c8ad/BoneThicknessMapping/BoneThicknessMapping.py#L667-L668): Each run adds a new segmentation node, a segment editor node (removed), a model node, and two color-table nodes to the MRML scene. Nothing removes the previous run's nodes, so repeated executions clutter the scene and waste memory. Clicking 'Finish' only resets the widget state. Remove or reuse the previous run's nodes in click_finish or at the start of click_execute.
- [`CMakeLists.txt:12`](https://github.com/Auditory-Biophysics-Lab/SlicerBoneThicknessMappingExtension/blob/56c40be2e11af6534b84203f7977e2c6d0c9c8ad/CMakeLists.txt#L12): EXTENSION_SCREENSHOTURLS mixes two repository names. The first URL uses SlicerBoneThicknessMappingExtension, but the second uses Slicer-BoneThicknessMapping, which does not match the declared source repo. The screenshot in the extension manager will likely fail to load. This is cosmetic and does not block loading. Use the same repository name in both URLs, and ideally a commit SHA rather than master.
- [`BoneThicknessMapping/BoneThicknessMapping.py:809-810`](https://github.com/Auditory-Biophysics-Lab/SlicerBoneThicknessMappingExtension/blob/56c40be2e11af6534b84203f7977e2c6d0c9c8ad/BoneThicknessMapping/BoneThicknessMapping.py#L809-L810): rawNormal is computed by numpy.linalg.solve on three hit points. If they are collinear or degenerate, numpy raises LinAlgError. That exception is not caught, so one bad quad aborts the whole run (see the previous finding). Catch numpy.linalg.LinAlgError and skip that quad, or compute the normal with a cross product of two edge vectors.
- [`BoneThicknessMapping/BoneThicknessMapping.py:231`](https://github.com/Auditory-Biophysics-Lab/SlicerBoneThicknessMappingExtension/blob/56c40be2e11af6534b84203f7977e2c6d0c9c8ad/BoneThicknessMapping/BoneThicknessMapping.py#L231): The widget connects release_memory to aboutToQuit, but does not remove this observer/connection when the widget or module is unloaded or destroyed, which can lead to dangling references when Slicer shuts down or the module is reloaded. Disconnect or remove the aboutToQuit connection properly in cleanup or destructor if applicable.
