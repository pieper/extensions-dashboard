- [`BoneThicknessMapping/BoneThicknessMapping.py:586-590`](https://github.com/Auditory-Biophysics-Lab/SlicerBoneThicknessMappingExtension/blob/56c40be2e11af6534b84203f7977e2c6d0c9c8ad/BoneThicknessMapping/BoneThicknessMapping.py#L586-L590): The helper passes its second argument to setCurrentNodeID, but these branches provide a node object rather than its ID string. After toggling the scalar bar off and on, selecting the color node can fail rather than restoring the legend. Pass GetID() for the selected color node, as the result-radio handler does.
- [`BoneThicknessMapping/BoneThicknessMapping.py:761-765`](https://github.com/Auditory-Biophysics-Lab/SlicerBoneThicknessMappingExtension/blob/56c40be2e11af6534b84203f7977e2c6d0c9c8ad/BoneThicknessMapping/BoneThicknessMapping.py#L761-L765): VTK bounds are ordered xmin, xmax, ymin, ymax, zmin, zmax, but the depth pair uses castIndex instead of 2*castIndex. For Y and Z casts it uses bounds from the wrong axes; with sufficiently displaced or large volumes the padded ray endpoints may not span the segmentation, yielding incomplete or empty maps. Index the depth bounds with 2*castIndex and 2*castIndex+1, and test all six directions on translated and large volumes.
- [`BoneThicknessMapping/CMakeLists.txt:1`](https://github.com/Auditory-Biophysics-Lab/SlicerBoneThicknessMappingExtension/blob/56c40be2e11af6534b84203f7977e2c6d0c9c8ad/BoneThicknessMapping/CMakeLists.txt#L1): Only generic scripted-module tests are enabled; the listed repository has no dedicated test suite exercising thickness accuracy, cast directions, or error recovery. Regressions in the primary measurement workflow may therefore go unnoticed. Add synthetic-volume tests with known thicknesses, translated coordinates, varied spacing, and all cast directions.
- [`BoneThicknessMapping/BoneThicknessMapping.py:514-518`](https://github.com/Auditory-Biophysics-Lab/SlicerBoneThicknessMappingExtension/blob/56c40be2e11af6534b84203f7977e2c6d0c9c8ad/BoneThicknessMapping/BoneThicknessMapping.py#L514-L518): The processing sequence has no exception handler or finally block, while the execute controls are disabled in EXECUTING. If a calculation or Slicer API raises, the user cannot normally retry or finish from the module, and intermediate scene nodes may remain. Report errors to the user, clean up temporary nodes and restore a retryable state in a finally block.
- [`BoneThicknessMapping/BoneThicknessMapping.py:873-877`](https://github.com/Auditory-Biophysics-Lab/SlicerBoneThicknessMappingExtension/blob/56c40be2e11af6534b84203f7977e2c6d0c9c8ad/BoneThicknessMapping/BoneThicknessMapping.py#L873-L877): dimensions comes from image voxel counts, while hitPoint coordinates are surface physical coordinates. On volumes with sufficiently large spacing, or geometry whose physical extent exceeds that count, the ray can be too short to reach the far surface and the map records zero instead of thickness. Derive the ray length from physical surface bounds, allowing for orientation, and test different voxel spacings.
- [`BoneThicknessMapping/BoneThicknessMapping.py:866-869`](https://github.com/Auditory-Biophysics-Lab/SlicerBoneThicknessMappingExtension/blob/56c40be2e11af6534b84203f7977e2c6d0c9c8ad/BoneThicknessMapping/BoneThicknessMapping.py#L866-L869): The default gradient scale factor is 10, and these scaled values are inserted directly into the model's named thickness and air-cell scalar arrays. The color table divides its labels by 10, so the display can look correct, but users exporting or inspecting scalar values may interpret a 2 mm distance as 20. Store distances in millimeters and configure the lookup table independently, or explicitly identify and document the scaled units.
- [`BoneThicknessMapping/BoneThicknessMapping.py:808-810`](https://github.com/Auditory-Biophysics-Lab/SlicerBoneThicknessMappingExtension/blob/56c40be2e11af6534b84203f7977e2c6d0c9c8ad/BoneThicknessMapping/BoneThicknessMapping.py#L808-L810): Solving using absolute point coordinates fails for triangles whose plane passes through the origin or is degenerate. Only the first point of each accepted quad receives a normal, so boundary and isolated hit points retain the zero default; the later thickness rays have identical endpoints and are recorded as zero. An exception also interrupts the run. Compute translation-invariant normals from edge cross products or a VTK normals filter, handle degenerate triangles, and assign valid normals to every measured point.
