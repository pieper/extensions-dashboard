- [`CisternaMagnaVolumetry/CisternaMagnaVolumetryLib/cisterna_core.py:440-445`](https://github.com/niyaziacer/SlicerCisternaVolumetry/blob/39602329284f0769a109119faeb6a1d7df13878b/CisternaMagnaVolumetry/CisternaMagnaVolumetryLib/cisterna_core.py#L440-L445): Nibabel's orientation rows map input axes to output axes, whereas spacing in canonical order needs the inverse mapping. For a three-axis cyclic permutation with anisotropic voxels, distances and millimeter cutoffs are assigned to the wrong axes, producing incorrect masks and volumes despite correct reorientation of the array. Invert the orientation permutation, for example using its argsort, and test all axis permutations with unequal spacings.
- [`CisternaMagnaVolumetry/CisternaMagnaVolumetry.py:393-398`](https://github.com/niyaziacer/SlicerCisternaVolumetry/blob/39602329284f0769a109119faeb6a1d7df13878b/CisternaMagnaVolumetry/CisternaMagnaVolumetry.py#L393-L398): Calculating again, including on another patient, removes all segments from the first scene node with this name without warning. A user may have edited the previous result or have an unrelated segmentation with that name, so unsaved work is lost. A same-named node of another type also causes an exception. Create a uniquely named output by default, or let the user explicitly select an output and confirm replacement before modifying it.
- [`CisternaMagnaVolumetry/CisternaMagnaVolumetry.py:356-364`](https://github.com/niyaziacer/SlicerCisternaVolumetry/blob/39602329284f0769a109119faeb6a1d7df13878b/CisternaMagnaVolumetry/CisternaMagnaVolumetry.py#L356-L364): Same-sized T1 and SynthSeg volumes with different origins, spacing, orientations, or transforms skip resampling, so T1 intensities are sampled at wrong anatomical positions during CSF refinement. The VolBrain path similarly checks only array shape before combining the label arrays with T1 geometry. Compare complete image-to-world geometries including parent transforms; resample to a common reference or reject inputs that are not aligned.

- [`CisternaMagnaVolumetry/CisternaMagnaVolumetryLib/cisterna_core.py:311-315`](https://github.com/niyaziacer/SlicerCisternaVolumetry/blob/39602329284f0769a109119faeb6a1d7df13878b/CisternaMagnaVolumetry/CisternaMagnaVolumetryLib/cisterna_core.py#L311-L315): When no pons jump is found, the fallback slice need not contain any brainstem voxels; the later ant[pmj] lookup then raises a KeyError and calculation fails. - [`CisternaMagnaVolumetry/CisternaMagnaVolumetry.py:428-433`](https://github.com/niyaziacer/SlicerCisternaVolumetry/blob/39602329284f0769a109119faeb6a1d7df13878b/CisternaMagnaVolumetry/CisternaMagnaVolumetry.py#L428-L433): `CisternaMagnaVolumetryTest.test_ModuleImports` imports `cisterna_core` directly without calling `CisternaMagnaVolumetryLogic()._ensureDependencies()`. Because `cisterna_core.py` imports `nibabel` at top level (line 33), the automated self-test will fail with `ModuleNotFoundError: No module named 'nibabel'` in a fresh Slicer environment where `nibabel` has not yet been installed.
