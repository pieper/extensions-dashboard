- [`BabelBrain/BabelBrainLib/SyncProtocol.py:195-201`](https://github.com/ProteusMRIgHIFU/SlicerBabelBrain/blob/a3c72bfc7874d413739c4f4dea66b45d1e2ea73e/BabelBrain/BabelBrainLib/SyncProtocol.py#L195-L201): On a shared POSIX computer, when the home directory and newly created sync directory are traversable by other users, mode 0644 lets those users read the input JSON. BuildInput includes anatomical and segmentation paths, trajectory names and positions, which may contain identifiers or sensitive subject information; chmod also overrides a restrictive umask for the file. Create or validate the sync directory as private and keep synchronization files owner-readable and writable only, ensuring the same-user BabelBrain process can still access them.
- [`BabelBrain/BabelBrain.py:554-558`](https://github.com/ProteusMRIgHIFU/SlicerBabelBrain/blob/a3c72bfc7874d413739c4f4dea66b45d1e2ea73e/BabelBrain/BabelBrain.py#L554-L558): When a modified volume or non-NIfTI input is run, the extension exports it to a predictable name in the selected output directory without checking whether that file already exists. An existing image at that path, potentially another subject's scan or an earlier version, can be overwritten before the later warning is shown. Use a unique filename or explicitly check for an existing destination and obtain informed confirmation before replacing it.
- [`BabelBrain/BabelBrain.py:368-377`](https://github.com/ProteusMRIgHIFU/SlicerBabelBrain/blob/a3c72bfc7874d413739c4f4dea66b45d1e2ea73e/BabelBrain/BabelBrain.py#L368-L377): prepareT1w reports an affine mismatch that may misplace trajectories, but launch starts the external process before returning that warning. - [`BabelBrain/BabelBrain.py:663-664`](https://github.com/ProteusMRIgHIFU/SlicerBabelBrain/blob/a3c72bfc7874d413739c4f4dea66b45d1e2ea73e/BabelBrain/BabelBrain.py#L663-L664): findOutputFile only checks whether ~/.BabelBrainSync/BabelBrainOutput.json exists.
