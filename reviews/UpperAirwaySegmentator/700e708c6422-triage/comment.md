- [`UpperAirwaySegmentator/UpperAirwaySegmentatorLib/PythonDependencyChecker.py:47-51`](https://github.com/capenaka/SlicerUpperAirwaySegmentator/blob/700e708c642233c0557a623fed4ed983d6369cd2/UpperAirwaySegmentator/UpperAirwaySegmentatorLib/PythonDependencyChecker.py#L47-L51): The download URL is whatever asset happens to be first across all releases, not a named weights archive; adding any other asset to a release (or a release with no assets) makes the module download the wrong file or raise IndexError. Unauthenticated GitHub API calls are also rate-limited per IP, so areWeightsOutdated() can fail for users behind a shared NAT (only GithubException is caught, not rate-limit/connection errors). Select the asset by an expected file name/pattern and handle network/rate-limit errors explicitly.
- [`UpperAirwaySegmentator/UpperAirwaySegmentatorLib/PythonDependencyChecker.py:86-88`](https://github.com/capenaka/SlicerUpperAirwaySegmentator/blob/700e708c642233c0557a623fed4ed983d6369cd2/UpperAirwaySegmentator/UpperAirwaySegmentatorLib/PythonDependencyChecker.py#L86-L88): destWeightFolder resolves to <extension>/UpperAirwaySegmentatorLib/../Resources/ML (SegmentationWidget.py:584-587). Anything a user placed there following the manual-install instructions in README.md:100-112 is deleted before the new download, and if the download then fails the user is left with nothing. The path is contained in the extension folder, so this is not user-data destruction, but it is an unconditional recursive delete of a directory the user may have curated. Download to a temporary directory, verify, then swap; never rmtree the existing weights before a successful download.
- [`UpperAirwaySegmentator/UpperAirwaySegmentatorLib/PythonDependencyChecker.py:116-117`](https://github.com/capenaka/SlicerUpperAirwaySegmentator/blob/700e708c642233c0557a623fed4ed983d6369cd2/UpperAirwaySegmentator/UpperAirwaySegmentatorLib/PythonDependencyChecker.py#L116-L117): extractall() honours '../' and absolute member names, so a tampered or replaced release asset would write outside Resources/ML (e.g. over other files in the extension install directory). There is also no checksum/signature check on the downloaded zip (lines 90-100), and the URL is taken from `assets[0]` of the latest release (line 51), i.e. whatever asset happens to be first. Risk is limited because the source is the author's own HTTPS release, but the extraction is unguarded. Validate each member path against the destination folder before extracting, and pin/verify a checksum for the expected weights archive.
- [`UpperAirwaySegmentator/UpperAirwaySegmentatorLib/SegmentationWidget.py:563-567`](https://github.com/capenaka/SlicerUpperAirwaySegmentator/blob/700e708c642233c0557a623fed4ed983d6369cd2/UpperAirwaySegmentator/UpperAirwaySegmentatorLib/SegmentationWidget.py#L563-L567): Clicking Apply runs NNUNet's setupPythonRequirements(), which installs nnunetv2 and PyTorch (multi-GB) into Slicer's shared Python. Using the NNUNet extension's install logic is the sanctioned route, but this extension adds no confirmation dialog of its own before the install, so a user who just wanted to try the module can trigger a large environment change. Whether NNUNet's InstallLogic prompts internally could not be verified. Show an explicit confirmation (size, packages, that Slicer's Python environment will be modified) before calling setupPythonRequirements().
- [`UpperAirwaySegmentator/UpperAirwaySegmentatorLib/SegmentationWidget.py:584-587`](https://github.com/capenaka/SlicerUpperAirwaySegmentator/blob/700e708c642233c0557a623fed4ed983d6369cd2/UpperAirwaySegmentator/UpperAirwaySegmentatorLib/SegmentationWidget.py#L584-L587): Weights are written into the extension installation folder rather than a user data or temporary directory. That folder is replaced on extension update/reinstall (forcing a re-download), may be read-only in system-wide installs, and the README itself documents Windows 260-character path failures caused by this location (README.md:114-121). The unit tests also write download_info.json into this installed folder (Testing/Utils.py:15-26). Store weights under slicer.util.getUserResourceDirectory() or a user-selectable folder, and let the tests use a temporary directory.
- [`UpperAirwaySegmentator/UpperAirwaySegmentatorLib/SegmentationWidget.py:172-179`](https://github.com/capenaka/SlicerUpperAirwaySegmentator/blob/700e708c642233c0557a623fed4ed983d6369cd2/UpperAirwaySegmentator/UpperAirwaySegmentatorLib/SegmentationWidget.py#L172-L179): This runs from __init__ (line 156) and again on every scene close, so merely opening the module switches the application layout to ConventionalWidescreen, forces a white 3D background and hides the orientation cube/axis labels for all view nodes (Utils.py:43-61). The user's previous layout and view settings are never saved or restored, which surprises users who open the module and then switch to another module. Apply these display changes only when the user starts a segmentation, and restore the previous layout/view node settings in cleanup().
