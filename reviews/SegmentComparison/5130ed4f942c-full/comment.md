Please fix these before the extension can be merged:

- [`BLD/BLD.py:19-23`](https://github.com/fbrewster/SlicerSegmentComparison/blob/5130ed4f942cd403b0d6027a2ce18fb8701312d1/BLD/BLD.py#L19-L23): BLD.py runs at Slicer startup, when the module is registered. If pandas is missing, it runs pip_install in the shared Python environment for every user, with no prompt. The bare `except:` also catches unrelated errors. Installation failures at startup can be silent or disruptive, and the install may need network access. Do not install at import. Either drop the pandas dependency (numpy and csv cover this use), or import pandas lazily inside the logic or export functions. Ask the user before installing, and catch only ImportError.

Smaller suggestions:

- [`BLD/BLD.py:303-311`](https://github.com/fbrewster/SlicerSegmentComparison/blob/5130ed4f942cd403b0d6027a2ce18fb8701312d1/BLD/BLD.py#L303-L311): A vertex within more than one directional margin is assigned only to the first matching direction, contrary to the documented independently defined subsets. If the x extent is smaller than the margin, every point is assigned R, leaving other regions empty and causing the maxima calculation to fail. Use an independent boolean mask for each direction and explicitly handle empty regions; test small and overlapping extents.
- [`BLD/BLD.py:406-409`](https://github.com/fbrewster/SlicerSegmentComparison/blob/5130ed4f942cd403b0d6027a2ce18fb8701312d1/BLD/BLD.py#L406-L409): The HD and HD95 calculations at lines 442-443 use this filtered dataframe, although the README describes a whole-segment metric. Distances at vertices outside the margin regions, including B points assigned to those vertices, are omitted, so the reported HD can underestimate the true maximum and HD95 changes with the region margin. Compute the bidirectional distances and whole-surface metrics before filtering for directional reporting, and add numerical regression tests.
- [`BLD/BLD.py:515-517`](https://github.com/fbrewster/SlicerSegmentComparison/blob/5130ed4f942cd403b0d6027a2ce18fb8701312d1/BLD/BLD.py#L515-L517): Append mode calls pd.read_pickle on a file chosen in the UI. Unpickling an untrusted .pkl file can execute arbitrary code. The file is user-chosen, so the risk is modest, but the format is unnecessary for the extension's purpose. Drop the pickle format, or warn the user that only trusted files should be loaded.
- [`BLD/BLD.py:228-234`](https://github.com/fbrewster/SlicerSegmentComparison/blob/5130ed4f942cd403b0d6027a2ce18fb8701312d1/BLD/BLD.py#L228-L234): Vector drawing is enabled by default. Any preexisting markup line named R, L, A, P, S or I can be found and its control points replaced when a comparison is run, even if the line belongs to the user's existing scene. Create and track module-owned output nodes using node references or unique identifiers, rather than looking up arbitrary scene nodes by common names.
- [`BLD/BLD.py:505-506`](https://github.com/fbrewster/SlicerSegmentComparison/blob/5130ed4f942cd403b0d6027a2ce18fb8701312d1/BLD/BLD.py#L505-L506): Exporting or appending to `.xlsx` via `pandas.DataFrame.to_excel` and `pd.read_excel` requires an Excel engine such as `openpyxl`, which is not bundled with Slicer or installed by `pip_install('pandas')`. Choosing the Excel format will raise an `ImportError` unless `openpyxl` is installed. Either install `openpyxl` on demand when Excel export is requested or remove Excel from the format options if only CSV is needed.
- [`BLD/BLD.py:351-357`](https://github.com/fbrewster/SlicerSegmentComparison/blob/5130ed4f942cd403b0d6027a2ce18fb8701312d1/BLD/BLD.py#L351-L357): With resample enabled, the module deletes the closed-surface representation of the input segmentations and sets the labelmap as source. The README warns about this, but the data are modified as a side effect of a measurement. Work on a temporary copy of the segmentation instead of modifying the input.
- [`STAPLE/STAPLE.py:315-320`](https://github.com/fbrewster/SlicerSegmentComparison/blob/5130ed4f942cd403b0d6027a2ce18fb8701312d1/STAPLE/STAPLE.py#L315-L320): When two selected segments share a name, the later labelmap replaces the earlier dictionary entry. STAPLE then processes fewer observers than selected and may produce a different consensus without warning. Store inputs in an ordered list keyed by segment ID, retaining display names separately, and validate the number of included labelmaps after visibility filtering.
