Suggestions for a later update:

- [`DICOMGatedDynamicPET/DynamicPETModeling.py:394-397`](https://github.com/4burakfe/SlicerPET4D/blob/7e1112e5eda734cfa1c3e975a3e77c5416b1df12/DICOMGatedDynamicPET/DynamicPETModeling.py#L394-L397): The save dialog selects the results filename, but exporting results.csv also truncates an existing results_TACs.csv without asking about that separate file. A user can lose unrelated existing data even when the selected results filename was new. Check both output paths before writing and explicitly confirm replacement of each existing file, or let the user choose a non-conflicting companion filename.
- [`DICOMGatedDynamicPET/DynamicPETModeling.py:324-329`](https://github.com/4burakfe/SlicerPET4D/blob/7e1112e5eda734cfa1c3e975a3e77c5416b1df12/DICOMGatedDynamicPET/DynamicPETModeling.py#L324-L329): The GUI always selects a reference segment, including for plasma-file models; this unconditional exclusion skips that segment in Fit all. With one target segment and a plasma curve, preview is allowed but Fit all produces no segment result. Allow an optional whole-blood segment for plasma-file models and include the selected target in batch fitting when it is not actually being used as a reference input.
- [`DICOMGatedDynamicPET/DICOMGatedDynamicPETLib/kinetics.py:865-867`](https://github.com/4burakfe/SlicerPET4D/blob/7e1112e5eda734cfa1c3e975a3e77c5416b1df12/DICOMGatedDynamicPET/DICOMGatedDynamicPETLib/kinetics.py#L865-L867): When a target segment has no voxels on some frame grids, segmentCurves records NaN for those frames, but this sum ignores the missing numerator while retaining its duration in the denominator. If the reference is present and the target exists in at least one frame, SUVR can be reported too low without a missing-data warning. Reject incomplete curves or compute both target and reference on a common set of finite frames, with an explicit warning.
