- [`HexaMesher/HexaMesher.py:5-8`](https://github.com/DomenicoRiggio/SlicerHexaMesher/blob/2492d1972f91271570166534746e4bf20a7301e0/HexaMesher/HexaMesher.py#L5-L8): The module mutates the global sys.path at import time to make the top-level package name 'HexaMesherLib' importable.
