- [`SlicerMLArray/SlicerMLArrayLib/slicer_io.py:173-176`](https://github.com/MIC-DKFZ/SlicerMLArray/blob/c42898796d375872738ba5f420b5a54cb885762a/SlicerMLArray/SlicerMLArrayLib/slicer_io.py#L173-L176): A 64-bit label or instance ID outside the signed 32-bit range wraps without warning; for example, 4294967296 becomes zero and is treated as background. - [`SlicerMLArray/SlicerMLArrayLib/slicer_io.py:229-233`](https://github.com/MIC-DKFZ/SlicerMLArray/blob/c42898796d375872738ba5f420b5a54cb885762a/SlicerMLArray/SlicerMLArrayLib/slicer_io.py#L229-L233): A small labelmap with a single large positive label ID requests a color table proportional to the ID and initializes every intermediate entry on the GUI thread.
