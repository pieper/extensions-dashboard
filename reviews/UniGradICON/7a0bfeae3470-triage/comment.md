Suggestions for a later update:

- [`UniGradICON/UniGradICONHelpers/registration.py:62-67`](https://github.com/uncbiag/SlicerUniGradICON/blob/7a0bfeae3470994753ff45f4b31ac8edca13a5dc/UniGradICON/UniGradICONHelpers/registration.py#L62-L67): Weights come from GitHub release URLs over HTTPS but are not verified against a known hash before being loaded. A compromised or replaced release asset would be used silently. The impact is limited because the file is loaded with torch.load(..., weights_only=True) (line 99), so no arbitrary code execution, but a tampered model would produce wrong registrations without any signal. Pin and verify a SHA-256 of each weights file before os.replace().
- [`UniGradICON/UniGradICONHelpers/remote.py:28-31`](https://github.com/uncbiag/SlicerUniGradICON/blob/7a0bfeae3470994753ff45f4b31ac8edca13a5dc/UniGradICON/UniGradICONHelpers/remote.py#L28-L31): Entering "host:8899" sends the fixed/moving images, masks and segmentations unencrypted over the network; the README does advise an SSH tunnel or HTTPS outside a trusted network, but the client neither warns nor requires TLS. On an untrusted network this exposes patient images and the access token in transit. Warn in the UI when the configured server URL is plain http and not localhost, or support/encourage https.
- [`README.md:5`](https://github.com/uncbiag/SlicerUniGradICON/blob/7a0bfeae3470994753ff45f4b31ac8edca13a5dc/README.md#L5): The module runs a deep-learning registration model on clinical images and writes transforms/volumes into the scene, but the README and module help text contain no statement that results are for research use and must be verified before clinical use. Model provenance (papers, weights source) is otherwise well documented. Add a short research-use-only disclaimer to README.md and to the module helpText/acknowledgementText.
- [`CMakeLists.txt:13`](https://github.com/uncbiag/SlicerUniGradICON/blob/7a0bfeae3470994753ff45f4b31ac8edca13a5dc/CMakeLists.txt#L13): UniGradICONLib/logic.py imports PyTorchUtils and raises "This module requires PyTorch extension. Install it from the Extensions Manager." when it is missing, and the catalog entry has build_dependencies []. Users who install UniGradICON for local registration therefore get a runtime error instead of the PyTorch extension being installed with it. Remote-only use works without it, so this is not a loading failure. Declare PyTorch in EXTENSION_DEPENDS and in the catalog entry's build_dependencies, or state clearly in the module UI that local registration needs a separate install.
- [`UniGradICON/UniGradICON.py:40`](https://github.com/uncbiag/SlicerUniGradICON/blob/7a0bfeae3470994753ff45f4b31ac8edca13a5dc/UniGradICON/UniGradICON.py#L40): The module requires PyTorchUtils for local registration, but parent.dependencies is empty and EXTENSION_DEPENDS is "NA". The module handles the missing extension at runtime, so this is not a load failure, but Slicer will not install PyTorch automatically. Declare PyTorch (or PyTorchUtils) as a dependency in CMake and in the catalog's build_dependencies if the index build should install it, or confirm this is intended.
- [`UniGradICON/UniGradICONLib/server.py:296`](https://github.com/uncbiag/SlicerUniGradICON/blob/7a0bfeae3470994753ff45f4b31ac8edca13a5dc/UniGradICON/UniGradICONLib/server.py#L296): Starting the local server installs fastapi/uvicorn/python-multipart into Slicer's shared environment after a confirmation dialog. This is user-initiated and confirmed, but it adds unpinned web-server packages to every module in that Slicer, and a later version change can break the server without notice. Pin compatible versions and document that these packages are added to Slicer's Python.
- [`UniGradICON/UniGradICON.py:23`](https://github.com/uncbiag/SlicerUniGradICON/blob/7a0bfeae3470994753ff45f4b31ac8edca13a5dc/UniGradICON/UniGradICON.py#L23): The main module imports the self-test class at load time, so test code and its dependencies load whenever the module loads. This adds import-time cost and a coupling risk. It is not a safety issue. Import the test class lazily or only when the self-test is run.
