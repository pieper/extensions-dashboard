- [`diffusionqclib/diffusionqclib/saveResults.py:73`](https://github.com/pnlbwh/SlicerDiffusionQC/blob/3c5a458203806c087193c8a822b637baba55fbb9/diffusionqclib/diffusionqclib/saveResults.py#L73): saveDWI and saveTemporary write *_modified.nrrd, *_QC.csv, and *_QC.npy into the input or chosen output directory, replacing any existing files with the same prefix. The README states this, but the GUI gives no confirmation, so a previous review can be lost. Warn or ask before overwriting, or write to a timestamped name.
- [`Test/run_test.py:57-65`](https://github.com/pnlbwh/SlicerDiffusionQC/blob/3c5a458203806c087193c8a822b637baba55fbb9/Test/run_test.py#L57-L65): run_test.py prints pass/fail but never sets a non-zero exit code, so the CTest entry passes regardless. The difference check is one-sided (a-b).sum() > eps, and the gradient loop uses len(np.where(...)), which is always 1. The test therefore gives no regression protection. Use sys.exit(1) on failure, compare absolute differences with np.allclose, and fix the len(np.where(csv==1)) expression.
- [`diffusionqclib/diffusionqclib/gradient_process.py:59-60`](https://github.com/pnlbwh/SlicerDiffusionQC/blob/3c5a458203806c087193c8a822b637baba55fbb9/diffusionqclib/diffusionqclib/gradient_process.py#L59-L60): load_mask calls img.get_data() on NIfTI masks. This method was removed in nibabel 5.0, so mask loading fails for NIfTI masks when the upgraded nibabel is installed. Use np.asanyarray(img.dataobj) or img.get_fdata().
- [`diffusionqclib/diffusionqclib/nhdr_write.py:72-74`](https://github.com/pnlbwh/SlicerDiffusionQC/blob/3c5a458203806c087193c8a822b637baba55fbb9/diffusionqclib/diffusionqclib/nhdr_write.py#L72-L74): nhdr_write sets sys.stdout to the file and only restores it on success. Any exception raised while writing the header leaves sys.stdout pointing at a closed file for the rest of the Slicer session. Write with an explicit file handle or wrap in try/finally to restore sys.stdout and close the file.
