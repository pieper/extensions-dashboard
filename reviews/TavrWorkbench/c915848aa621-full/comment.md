Smaller suggestions:

- [`TavrWorkbench/TavrWorkbench.py:46-47`](https://github.com/pcdslab/TavrWorkbench/blob/c915848aa62164d373166e7c2fd9984f5f8c826e/TavrWorkbench/TavrWorkbench.py#L46-L47): At module import time (when Slicer starts up and discovers scripted modules), `TavrWorkbench.py` disables VTK warning display globally across the entire Slicer process. This affects all users and all other modules even if the user never opens `TavrWorkbench`. Remove `vtk.vtkObject.GlobalWarningDisplayOff()` at import time, or scope warning suppression locally around specific noisy operations and restore the previous `GlobalWarningDisplay` state in a `finally:` block.
- [`TavrWorkbench/TavrWorkbenchLib/storage.py:39-41`](https://github.com/pcdslab/TavrWorkbench/blob/c915848aa62164d373166e7c2fd9984f5f8c826e/TavrWorkbench/TavrWorkbenchLib/storage.py#L39-L41): A manifest case_id of '..' remains '..'; case_dir joins it to the selected output root, so saving a review or mask writes into its parent and can overwrite existing review.json or segmentation.seg.nrrd. Distinct IDs such as 'a/b' and 'ab' also map to the same folder, so one case can overwrite another case's corrections while their status entries remain distinct. Reject '.' and '..', enforce resolved-path containment, and use a collision-resistant mapping or reject duplicate normalized case IDs before loading.
- [`TavrWorkbench/tools/package_dataset.py:121-131`](https://github.com/pcdslab/TavrWorkbench/blob/c915848aa62164d373166e7c2fd9984f5f8c826e/TavrWorkbench/tools/package_dataset.py#L121-L131): safe_name permits the case ID '..', and package constructs case_rel as cases/<ID>. For such a manifest, cleanup walks cases/.., i.e. the whole selected output directory, and removes files not in the new entry, including unrelated data. Even normal IDs cause untracked files in an existing case folder to be deleted without confirmation. Reject dot components, verify resolved paths remain beneath a dedicated case directory, and remove only files recorded as generated by a previous run, with explicit confirmation or a non-destructive default.
- [`install/install_mac.sh:224-231`](https://github.com/pcdslab/TavrWorkbench/blob/c915848aa62164d373166e7c2fd9984f5f8c826e/install/install_mac.sh#L224-L231): The installer may reuse an existing same-version Slicer application, not necessarily one it installed. If macOS terminates that process during configuration, the recovery path can recursively delete that application without asking, including any user modifications stored in it; a process termination does not prove the application is disposable. Never automatically remove an existing Slicer application; install a separate copy or request explicit confirmation after identifying its ownership and backing it up.
- [`TavrWorkbench/TavrWorkbench.py:513-520`](https://github.com/pcdslab/TavrWorkbench/blob/c915848aa62164d373166e7c2fd9984f5f8c826e/TavrWorkbench/TavrWorkbench.py#L513-L520): The leave check covers hinge and measurement edits but not segmentation edits. - [`TavrWorkbench/TavrWorkbench.py:538-542`](https://github.com/pcdslab/TavrWorkbench/blob/c915848aa62164d373166e7c2fd9984f5f8c826e/TavrWorkbench/TavrWorkbench.py#L538-L542): _loadCaseData returns False when the image cannot be loaded, but this caller ignores the result and sets _case_loaded to True.
