- [`src/carreraslice_wrap/CarreraSliceEffect.py:358`](https://github.com/ikolesov/CarreraSlice/blob/7eae88259f89a302cf59c74b2baed7add0eb15ef/src/carreraslice_wrap/CarreraSliceEffect.py#L358): KSliceEffectLogic.__init__ calls removeShortcutKeys() on the Editor widget, and only a successful destroy() restores them. Combined with the NameError described above, a user who uses the effect and then closes or reloads the module can be left with Editor shortcuts disabled. Pair the removal with a guaranteed restore in a finally or cleanup path, and document the global side effect.
- [`src/carreraslice_wrap/CarreraSliceEffect.py:91`](https://github.com/ikolesov/CarreraSlice/blob/7eae88259f89a302cf59c74b2baed7add0eb15ef/src/carreraslice_wrap/CarreraSliceEffect.py#L91): The bot stores itself on the shared `slicer.modules` object and deletes other extensions' bots (`slicer.modules.FGCEditorBot`, line 157-159), and line 358 removes the Editor's global keyboard shortcuts. These are process-wide side effects that affect other modules while the effect is active; they are scoped to the effect's lifetime but are fragile and can leave Slicer in a modified state if destroy() is not reached. Keep the bot reference on the effect instance and restore shortcuts in a try/finally.
