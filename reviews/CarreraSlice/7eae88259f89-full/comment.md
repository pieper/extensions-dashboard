Smaller suggestions:

- [`src/fastGrowCut/Logic/utilities.h:111-115`](https://github.com/ikolesov/CarreraSlice/blob/7eae88259f89a302cf59c74b2baed7add0eb15ef/src/fastGrowCut/Logic/utilities.h#L111-L115): vtkFastGrowCut.h defines SrcPixelType as short, and vtkFastGrowCut.cxx passes the user-selected source image to this template without a scalar-type check. An unsigned-char source is read as two-byte values, potentially reading beyond the allocated final voxel; other types are misinterpreted and produce incorrect segmentation. The Python entry point accepts the image without converting it. Validate scalar types and component counts, or convert inputs to supported types before native processing; use type-dispatched VTK access and test boundary voxels.
- [`src/carreraslice_wrap/CarreraSliceEffect.py:255-260`](https://github.com/ikolesov/CarreraSlice/blob/7eae88259f89a302cf59c74b2baed7add0eb15ef/src/carreraslice_wrap/CarreraSliceEffect.py#L255-L260): CMake includes CarreraSliceEffect and KUtil as scripted modules. Both contain Python 2 print statements, which cause SyntaxError in Python 3 before the effect can be registered; the code also depends on the legacy Editor API. This is ordinary extension functionality feedback, separate from catalog admission. Port the module and KUtil to Python 3 and the supported Segment Editor API, then exercise loading and segmentation in a current Slicer release.
- [`src/CMakeLists.txt:28-29`](https://github.com/ikolesov/CarreraSlice/blob/7eae88259f89a302cf59c74b2baed7add0eb15ef/src/CMakeLists.txt#L28-L29): `src/CMakeLists.txt` uses legacy CMake/VTK variables (`include(${VTK_USE_FILE})`, `${QT_include_DIR}`, `${QT_LIBRARIES}`) and sets `CMAKE_INSTALL_PREFIX` to `${Slicer_DIR}` (line 92), which are incompatible with modern Slicer 5 / VTK 9 / Qt 5 builds. Update the CMake configuration for modern Slicer/VTK/ITK targets and remove manual overrides of `CMAKE_INSTALL_PREFIX`, `EXECUTABLE_OUTPUT_PATH`, and `LIBRARY_OUTPUT_PATH`.
- [`src/carreraslice_wrap/CarreraSliceEffect.py:1-7`](https://github.com/ikolesov/CarreraSlice/blob/7eae88259f89a302cf59c74b2baed7add0eb15ef/src/carreraslice_wrap/CarreraSliceEffect.py#L1-L7): CarreraSliceEffect.py and KUtil.py are written for Python 2 and Slicer 4's legacy Editor module (`EditorLib`, `print "..."`, `xrange`, `from __main__ import vtk, qt, ctk, slicer`). In modern Slicer 5 (Python 3, Segment Editor), importing `CarreraSliceEffect.py` fails immediately with a `SyntaxError` on Python 2 `print` statements (e.g. line 260) and `ModuleNotFoundError` for `EditorLib`. Port the Python code to Python 3 and migrate the effect from the removed Slicer 4 `EditorLib` framework to Slicer 5's `SegmentEditorEffects` framework (or archive the extension if it is unmaintained).
- [`src/carreraslice_wrap/CarreraSliceEffect.py:743`](https://github.com/ikolesov/CarreraSlice/blob/7eae88259f89a302cf59c74b2baed7add0eb15ef/src/carreraslice_wrap/CarreraSliceEffect.py#L743): On a paint event the code converts all nonzero labels on the slice to a Boolean mask, then assigns self.labVal * newLab to the entire slice at line 802; neighboring slices are similarly reassigned at lines 821–827. In an existing multi-label labelmap, even untouched structures on those slices are silently converted to the current label, destroying their identities. The slice is also cleared on mouse press before the edit completes. Preserve every unrelated label value, limit writes to the actual painted or erased voxels, and provide a proper undo snapshot; test with multiple pre-existing labels and interrupted interactions.
- [`src/carreraslice_wrap/CarreraSliceEffect.py:967-974`](https://github.com/ikolesov/CarreraSlice/blob/7eae88259f89a302cf59c74b2baed7add0eb15ef/src/carreraslice_wrap/CarreraSliceEffect.py#L967-L974): The R shortcut invokes this function while the bot is active. Although presented as resetting Fast GrowCut parameters, it zeroes every voxel of the user's active label volume, including any pre-existing segmentation, without confirmation or an undo snapshot in this path. Reset only internal state or work on a separate seed node; if clearing user data is necessary, explicitly confirm and save an undo state first.
- [`src/carreraslice_wrap/CarreraSliceEffect.py:482`](https://github.com/ikolesov/CarreraSlice/blob/7eae88259f89a302cf59c74b2baed7add0eb15ef/src/carreraslice_wrap/CarreraSliceEffect.py#L482): Initialization removes the Editor's shortcut keys and installs mouse_obs_growcut. If the user stops before starting the level-set phase, destroy returns here without removing those mouse observers or reinstalling Editor shortcuts, leaving callbacks active and normal shortcuts disabled. Always remove GrowCut observers from their original owners and restore Editor shortcuts, including on initialization failure and early stop.
