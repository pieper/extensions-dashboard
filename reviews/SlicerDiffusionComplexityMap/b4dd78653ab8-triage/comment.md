Suggestions for a later update:

- [`DiffusionComplexityMap/itkDiffusionComplexityMappingImageFilter.hxx:299-300`](https://github.com/CSIM-Toolkits/SlicerDiffusionComplexityMap/blob/b4dd78653ab80be20a0d3bec7334ad641d277d25/DiffusionComplexityMap/itkDiffusionComplexityMappingImageFilter.hxx#L299-L300): numberOfReferenceImages is derived from the number of components minus the number of non-zero gradients; a DWI without a b0 volume (or with headers lacking DWMRI_gradient tags, as in the bundled test data) makes it 0, so the mean S0 becomes inf/NaN and every downstream diffusion value and the whole DC map are NaN. The missing b-value case is only printed as a warning (line 200-203) and processing continues. Validate that at least one b0 volume and at least one gradient exist and abort with a clear error message otherwise.
- [`DiffusionComplexityMap/DiffusionComplexityMap.xml:21`](https://github.com/CSIM-Toolkits/SlicerDiffusionComplexityMap/blob/b4dd78653ab80be20a0d3bec7334ad641d277d25/DiffusionComplexityMap/DiffusionComplexityMap.xml#L21): The extra '>' becomes character data inside the <image> element. It is well-formed XML so the module still loads, but it is a malformed parameter declaration that can confuse the SlicerExecutionModel parser and any tooling that reads the XML. Remove the stray '>' so the line reads '<image type="label">'.
- [`DiffusionComplexityMap/itkDiffusionComplexityMappingImageFilter.hxx:398-403`](https://github.com/CSIM-Toolkits/SlicerDiffusionComplexityMap/blob/b4dd78653ab80be20a0d3bec7334ad641d277d25/DiffusionComplexityMap/itkDiffusionComplexityMappingImageFilter.hxx#L398-L403): numberOfBins is an unsigned int computed from a double division; if max == min (constant or all-zero diffusion values inside the mask) the result is 0. Histogram::Initialize is then called with size 0 and, in calculatesDisequilibriumMapping line 545, 'p_e = 1.0/m_HistogramBins' divides by zero, producing inf/NaN output or an ITK exception. Clamp the computed bin count to a sane minimum (e.g. 4, matching the XML constraint) and guard against max == min before building the histogram.
- [`DiffusionComplexityMap/itkDiffusionComplexityMappingImageFilter.h:2-15`](https://github.com/CSIM-Toolkits/SlicerDiffusionComplexityMap/blob/b4dd78653ab80be20a0d3bec7334ad641d277d25/DiffusionComplexityMap/itkDiffusionComplexityMappingImageFilter.h#L2-L15): The filter sources state Apache-2.0 with a different copyright holder, while the repository LICENSE and README say MIT. Both permit distribution, so this is not blocking, but users and packagers cannot tell which terms apply to the filter code. Clarify in LICENSE or the headers which license covers the ITK filter files, and make the copyright holders consistent.
- [`DiffusionComplexityMap/DiffusionComplexityMap.cxx:70-71`](https://github.com/CSIM-Toolkits/SlicerDiffusionComplexityMap/blob/b4dd78653ab80be20a0d3bec7334ad641d277d25/DiffusionComplexityMap/DiffusionComplexityMap.cxx#L70-L71): DebugModeOn() is hard-coded, so every run prints the NRRD metadata keys, gradient counts and bin counts to stdout. This clutters the Slicer CLI output window for all users and cannot be turned off from the GUI. Expose debug mode as a boolean CLI parameter defaulting to false, or remove the call.
- [`DiffusionComplexityMap/CMakeLists.txt:16-19`](https://github.com/CSIM-Toolkits/SlicerDiffusionComplexityMap/blob/b4dd78653ab80be20a0d3bec7334ad641d277d25/DiffusionComplexityMap/CMakeLists.txt#L16-L19): The code includes itkDiffusionTensor3DReconstructionImageFilter.h and itkNrrdImageIO.h, but only ITKIOImageBase and ITKSmoothing are requested in find_package. Depending on the ITK build, the link or include could fail. Not verified by building. Add the ITK modules that provide the DTI reconstruction and NRRD IO headers (for example ITKDiffusionTensorImage / ITKIONRRD) and confirm a clean build.
- [`DiffusionComplexityMap/itkDiffusionComplexityMappingImageFilter.hxx:200-203`](https://github.com/CSIM-Toolkits/SlicerDiffusionComplexityMap/blob/b4dd78653ab80be20a0d3bec7334ad641d277d25/DiffusionComplexityMap/itkDiffusionComplexityMappingImageFilter.hxx#L200-L203): If the DWMRI_b-value key is absent, b0 stays 0 and createDiffusionWeightedValues divides by it, yielding inf/NaN gradient values. The code prints only 'BValue not specified in header file' to cerr and proceeds, so the module reports success with a corrupt output. Raise an exception instead of continuing when the b-value is missing.
- [`DiffusionComplexityMap/itkDiffusionComplexityMappingImageFilter.hxx:161-169`](https://github.com/CSIM-Toolkits/SlicerDiffusionComplexityMap/blob/b4dd78653ab80be20a0d3bec7334ad641d277d25/DiffusionComplexityMap/itkDiffusionComplexityMappingImageFilter.hxx#L161-L169): x, y, z are declared without initialization and passed to sscanf. If a DWMRI_gradient metadata value is malformed, the vector gets indeterminate values, and the gradient is then used in the reference-vs-gradient decision. Initialize x, y, z to zero and check that sscanf returns 3.
