Please fix these before the extension can be merged:

- [`STNSegmenter/STNSegmenter.py:19`](https://github.com/IVarha/SlicerDBSCoalignment/blob/d1d9b946b46f05f6f40fd53305c84ac9e0e7c240/STNSegmenter/STNSegmenter.py#L19): Scripted modules are imported when Slicer loads the extension, so this runs for every user who installs DBSCoalignment, even if they never open STNSegmenter. It pulls a PyPI torch build (CPU/CUDA mismatch, large download, no user confirmation) into Slicer's shared Python and can break other extensions; the same pattern is at DBSShiftPrediction.py:17-25 and STNSegmenter.py:1745-1750 (torchio). Remove the import-time installs and use the Slicer PyTorch extension's PyTorchUtils (add PyTorch to build_dependencies and EXTENSION_DEPENDS), prompting the user before any download.

Smaller suggestions:

- [`STNSegmenter/STNSegmenter.py:19`](https://github.com/IVarha/SlicerDBSCoalignment/blob/d1d9b946b46f05f6f40fd53305c84ac9e0e7c240/STNSegmenter/STNSegmenter.py#L19): Weights are auto-downloaded from GitHub releases (line 730) and then unpickled with torch.load; on torch versions before 2.6 this can execute arbitrary code from the file. The same pattern is at lines 178 and DBSShiftPrediction.py:1761. Files are also loaded from the module resource directory, which is writable by the user. Pass weights_only=True (or load a safetensors file) and verify a published SHA256 of the downloaded weights.
- [`LICENSE.txt:1-3`](https://github.com/IVarha/SlicerDBSCoalignment/blob/d1d9b946b46f05f6f40fd53305c84ac9e0e7c240/LICENSE.txt#L1-L3): The extension code is MIT, but the repository ships trained networks (transformer_classifier_test.pt, shape_pcas.pkl, mer_pca_mesh.pkl, 3.obj) and MNI152-derived templates whose origin, training data and redistribution terms are not stated; MNI templates carry their own attribution terms. Users cannot tell what they may redistribute. Add a NOTICE/Resources README stating the source, license and training data of each bundled model and template.
- [`AtlasMapping/AtlasMapping.py:1178`](https://github.com/IVarha/SlicerDBSCoalignment/blob/d1d9b946b46f05f6f40fd53305c84ac9e0e7c240/AtlasMapping/AtlasMapping.py#L1178): AtlasMappingLogic.process is defined as process(self, inputMesh, inputBaseTransform) (line 866-868), so the bundled test raises TypeError immediately; the test also treats a model node as a volume (inputMesh.GetImageData()). The test therefore cannot validate anything. Rewrite the test against the real signature and a real input mesh/transform, or remove it.
- [`STNSegmenter/STNSegmenter.py:104-108`](https://github.com/IVarha/SlicerDBSCoalignment/blob/d1d9b946b46f05f6f40fd53305c84ac9e0e7c240/STNSegmenter/STNSegmenter.py#L104-L108): Model/histogram pickles are deserialized with pickle (also DBSShiftPrediction.py:1038). The files ship with the extension so the risk is limited, but pickle can execute code if a resource file is replaced, and the provenance of these pickles is undocumented. Prefer a non-executable format (npz/json) or document and checksum the pickle files.
- [`STNSegmenter/STNSegmenter.py:240-247`](https://github.com/IVarha/SlicerDBSCoalignment/blob/d1d9b946b46f05f6f40fd53305c84ac9e0e7c240/STNSegmenter/STNSegmenter.py#L240-L247): Contributors, help text and acknowledgement are the Slicer template defaults ('This is an example of scripted loadable module bundled in an extension'), so users get no in-application guidance for a neurosurgical workflow; the same applies to AtlasMapping.py:238-248, LabelConversion.py:49 and TextToMarkups.py:61. Fill in real contributors, help text and acknowledgements, and add a research-use disclaimer.
- [`README.md:1-5`](https://github.com/IVarha/SlicerDBSCoalignment/blob/d1d9b946b46f05f6f40fd53305c84ac9e0e7c240/README.md#L1-L5): The software supports surgical electrode placement, but the README and CMake metadata contain no statement that results are research-only and not for clinical decisions. Test suites are commented out (e.g., DBS_STN/Testing/Python/CMakeLists.txt), so there is no regression coverage. Add a research-use disclaimer, document model provenance and validation for the networks, and enable at least a smoke test.
- [`DBS_STN/CMakeLists.txt:6`](https://github.com/IVarha/SlicerDBSCoalignment/blob/d1d9b946b46f05f6f40fd53305c84ac9e0e7c240/DBS_STN/CMakeLists.txt#L6): DBS_STN/Resources/MNI/MNI152_T1_1mm_subbr_mask.nii.gz, Resources/elastix/*.txt, Resources/Smk_utils/*.smk and Resources/py/bet.py exist in the repository but are not listed in MODULE_PYTHON_RESOURCES, so they will not be present in an installed extension. Whether the runtime code needs them was not verified. Add the resources actually used at runtime to MODULE_PYTHON_RESOURCES, or delete the unused ones.
