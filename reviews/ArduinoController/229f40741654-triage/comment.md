- [`ArduinoConnect/ArduinoConnect.py:247-248`](https://github.com/pzaffino/SlicerArduinoController/blob/229f407416549b33f8431a960c7d0479a7a5b564/ArduinoConnect/ArduinoConnect.py#L247-L248): Observers added on the parameter node (ArduinoConnect.py:215-216), on the Arduino node by the plotter/monitor (ArduinoConnect.py:65,150) and by the pedal board/motion sensor (ArduinoPedalBoard.py:50, ArduinoMotionSensor.py:59) are never removed, and the observer tags are overwritten (ArduinoConnect.py:39 and :42 both assign sceneModifiedObserverTag). If the widget is destroyed or the scene is closed while a connection is active, callbacks run against deleted Qt widgets, producing exceptions or crashes. - [`ArduinoConnect/ArduinoConnect.py:352-356`](https://github.com/pzaffino/SlicerArduinoController/blob/229f407416549b33f8431a960c7d0479a7a5b564/ArduinoConnect/ArduinoConnect.py#L352-L356): Clearing or typing a non-numeric value in 'Samples' (or 'Samples/s', ArduinoConnect.py:423, or 'Offset' in ArduinoMotionSensor.py:56) raises ValueError inside a Qt slot; the exception is only printed to the console and the user gets no feedback, and the plot/connection silently does not update. - [`ArduinoConnect/ArduinoConnect.py:250-252`](https://github.com/pzaffino/SlicerArduinoController/blob/229f407416549b33f8431a960c7d0479a7a5b564/ArduinoConnect/ArduinoConnect.py#L250-L252): configFileName is derived from __file__ (ArduinoConnect.py:210), i.e. the extension's installed Resources folder. The stored path is later executed with subprocess.Popen (ArduinoConnect.py:330).
