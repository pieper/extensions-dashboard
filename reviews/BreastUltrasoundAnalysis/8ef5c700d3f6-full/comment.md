Please fix these before the extension can be merged:

- [`BUS_Diagnosis/BUS_Diagnosis.py:738`](https://github.com/ZhyBrian/SlicerBreastUltrasoundAnalysis/blob/8ef5c700d3f635d686ce1e820d88cce009baf3b1/BUS_Diagnosis/BUS_Diagnosis.py#L738): The weights come from a public Zoho WorkDrive URL via `requests.get(..., verify=False)`. There is no hash or signature check. The file is then passed to `torch.load` without `weights_only=True`, which unpickles it. A man-in-the-middle, or a change to the shared file, could run arbitrary code in Slicer. The same download function fetches the sample data. Remove `verify=False`. Host the weights at a stable release URL, for example a GitHub release. Verify a SHA256 checksum before loading. Use `torch.load(..., weights_only=True)`, or safetensors. Consider Slicer's SampleData or `slicer.util.downloadFile` with checksums.
- [`BUS_Diagnosis/BUS_Diagnosis.py:772`](https://github.com/ZhyBrian/SlicerBreastUltrasoundAnalysis/blob/8ef5c700d3f635d686ce1e820d88cce009baf3b1/BUS_Diagnosis/BUS_Diagnosis.py#L772): The weights file is unpickled with the default settings. Together with the unverified download, this is an unsafe deserialization path. Use `weights_only=True`.
- [`BUS_Diagnosis/BUS_Diagnosis.py:37-45`](https://github.com/ZhyBrian/SlicerBreastUltrasoundAnalysis/blob/8ef5c700d3f635d686ce1e820d88cce009baf3b1/BUS_Diagnosis/BUS_Diagnosis.py#L37-L45): When `import torch` fails, the module tries PyTorchUtils, but then always calls `slicer.util.pip_install('torch torchvision torchaudio')`, even if PyTorchUtils already succeeded. This runs at Slicer startup for every user, with no confirmation, and downloads a large package set. torchaudio is not needed. Errors from the PyTorchUtils install are swallowed. Installing torch outside the PyTorch extension can break Slicer's torch setup. Import torch lazily inside the logic or widget. Install only via `PyTorchUtils.PyTorchUtilsLogic().installTorch(askConfirmation=True)` when the user asks. Never call pip_install for torch. Drop torchaudio. Declare Pillow and torchvision as separate confirmed installs.

Smaller suggestions:

- [`BUS_Diagnosis/BUS_Diagnosis.py:445-448`](https://github.com/ZhyBrian/SlicerBreastUltrasoundAnalysis/blob/8ef5c700d3f635d686ce1e820d88cce009baf3b1/BUS_Diagnosis/BUS_Diagnosis.py#L445-L448): Clicking the `Install Pytorch` button directly runs `slicer.util.pip_install('torch torchvision torchaudio')` instead of using the Slicer `PyTorchUtils` extension. Installing `torch` directly from PyPI bypasses Slicer's hardware/CUDA detection in `PyTorchUtils` and can break or downgrade an existing PyTorch installation shared with other Slicer extensions. Use `PyTorchUtils.PyTorchUtilsLogic().installTorch(askConfirmation=True)` to install PyTorch rather than `slicer.util.pip_install('torch ...')`.
- [`BUS_Diagnosis/BUS_Diagnosis.py:608-615`](https://github.com/ZhyBrian/SlicerBreastUltrasoundAnalysis/blob/8ef5c700d3f635d686ce1e820d88cce009baf3b1/BUS_Diagnosis/BUS_Diagnosis.py#L608-L615): The output files receive origin and spacing but no direction matrix, so SimpleITK's default direction is used for both masks. For non-default orientations the saved masks can be physically misregistered when reloaded or used with other images; the output volume is also populated without copying input geometry. Preserve the input/reference volume's full geometry, including coordinate-system conversion and direction, and test saved-mask alignment after reload.
- [`BUS_Diagnosis/BUS_Diagnosis.py:895-903`](https://github.com/ZhyBrian/SlicerBreastUltrasoundAnalysis/blob/8ef5c700d3f635d686ce1e820d88cce009baf3b1/BUS_Diagnosis/BUS_Diagnosis.py#L895-L903): The code turns the red view's physical offset and bounds into an ascending array index without considering the volume's IJK-to-world orientation or the slice plane. Reversed or oblique image orientations can therefore analyze a different array slice from the one displayed, or yield an invalid index; the resulting classification is presented as the current slice's result. Transform the selected slice position through the volume's world-to-IJK matrix, validate orientation and bounds, and test reversed and oblique volumes.
- [`BUS_Diagnosis/BUS_Diagnosis.py:954-962`](https://github.com/ZhyBrian/SlicerBreastUltrasoundAnalysis/blob/8ef5c700d3f635d686ce1e820d88cce009baf3b1/BUS_Diagnosis/BUS_Diagnosis.py#L954-L962): The UI permits the same scalar volume to be selected as both input and output, and process checks only that the nodes exist. Applying then replaces the ultrasound image in the scene with a binary result; selecting an existing segmentation also replaces its first segment without warning. Saving the scene afterwards can persist the unintended loss of original data. Reject input/output aliasing and create a new segment or explicitly confirm replacement of existing segment and volume contents.
- [`BUS_Diagnosis/BUS_Diagnosis.py:550-553`](https://github.com/ZhyBrian/SlicerBreastUltrasoundAnalysis/blob/8ef5c700d3f635d686ce1e820d88cce009baf3b1/BUS_Diagnosis/BUS_Diagnosis.py#L550-L553): The save function writes the patient name, ID and birth date to a user-chosen folder. Warn about or optionally anonymize identifiers. Add a basic test and a research-use disclaimer.
