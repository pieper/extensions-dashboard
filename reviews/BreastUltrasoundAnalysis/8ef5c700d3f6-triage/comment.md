Please fix these before the extension can be merged:

- [`BUS_Diagnosis/BUS_Diagnosis.py:37`](https://github.com/ZhyBrian/SlicerBreastUltrasoundAnalysis/blob/8ef5c700d3f635d686ce1e820d88cce009baf3b1/BUS_Diagnosis/BUS_Diagnosis.py#L37): The module-level try/except ends in an unconditional pip_install of torch/torchvision/torchaudio, so importing the script (which happens when Slicer scans the qt-scripted-modules folder at startup, before the module is ever opened) installs PyPI torch into Slicer's shared Python, together with its own numpy/pillow pins. This affects users who never open the module and can break Slicer and other extensions; README.md:33 confirms the intent ('This module will install them automatically when you restart 3D Slicer for the first time'). The catalog declares PyTorch in build_dependencies/EXTENSION_DEPENDS, which is the supported route. Remove the pip_install fallback (and the duplicate one in onInstallPytorchButton, line 446); require torch via PyTorchUtils.installTorch/ensureTorch with a version list and let the PyTorch extension provide it, showing a clear error if unavailable.
