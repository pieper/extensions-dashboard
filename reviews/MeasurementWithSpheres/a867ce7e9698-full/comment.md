- [`MeasurementWithSpheres/MeasurementWithSpheres.py:410-414`](https://github.com/cagatayalptekin/SlicerMeasurementWithSpheres/blob/a867ce7e96984a11fdcedec0eed5704ddd16a7a8/MeasurementWithSpheres/MeasurementWithSpheres.py#L410-L414): Create Spheres unconditionally accesses 12 points from the first fiducial node and creates models before checking whether it exists or contains valid points. - [`MeasurementWithSpheres/MeasurementWithSpheres.py:74-79`](https://github.com/cagatayalptekin/SlicerMeasurementWithSpheres/blob/a867ce7e96984a11fdcedec0eed5704ddd16a7a8/MeasurementWithSpheres/MeasurementWithSpheres.py#L74-L79): The body of the `@​parameterNodeWrapper` class runs when the module file is imported, which Slicer does at startup or when the module list is built. It adds three line nodes and an angle node to the scene, and it creates vtk sphere sources. Users who never open the module get stray nodes in their scene, and they are duplicated on reload or scene change. Nothing else would normally touch the scene at import time. Declare typed parameter-node fields. Create the nodes lazily in the logic, only when the user clicks Create, and keep references by node ID.

- [`MeasurementWithSpheres/MeasurementWithSpheres.py:405-409`](https://github.com/cagatayalptekin/SlicerMeasurementWithSpheres/blob/a867ce7e96984a11fdcedec0eed5704ddd16a7a8/MeasurementWithSpheres/MeasurementWithSpheres.py#L405-L409): These methods retrieve positions in the markup node's local coordinates. - [`MeasurementWithSpheres/MeasurementWithSpheres.py:286-289`](https://github.com/cagatayalptekin/SlicerMeasurementWithSpheres/blob/a867ce7e96984a11fdcedec0eed5704ddd16a7a8/MeasurementWithSpheres/MeasurementWithSpheres.py#L286-L289): Many attributes are plain class attributes, not typed fields. - [`MeasurementWithSpheres/MeasurementWithSpheres.py:323-326`](https://github.com/cagatayalptekin/SlicerMeasurementWithSpheres/blob/a867ce7e96984a11fdcedec0eed5704ddd16a7a8/MeasurementWithSpheres/MeasurementWithSpheres.py#L323-L326): `createAngle` and `sphereFrom3Points` assume that a `vtkMRMLMarkupsFiducialNode` exists in the scene and has at least 12 control points, without checking. If no fiducial node exists, `markupsNode` is `None` and calling `GetNthControlPointPosition` raises an `AttributeError`. If fewer than 12 points exist, `GetNthControlPointPosition` leaves the points at `(0, 0, 0)`, resulting in division by zero in `sphereFrom3Points`. Also note that `sphereFrom3Points` computes the circumcircle in the plane of 3 points rather than a 4-point 3D sphere. Add a `qMRMLNodeComboBox` to let the user select the input `vtkMRMLMarkupsFiducialNode`, and check that the node exists and has at least 12 non-collinear control points before computing spheres, showing an informative error message if not.
