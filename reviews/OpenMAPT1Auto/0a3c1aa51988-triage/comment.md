Suggestions for a later update:

- [`OpenMAPT1AutoParcellation/OpenMAPT1AutoParcellation.py:179`](https://github.com/niyaziacer/SlicerOpenMAPT1Auto/blob/0a3c1aa519880a4c8f3d6110810b88829f9c615b/OpenMAPT1AutoParcellation/OpenMAPT1AutoParcellation.py#L179): Pressing "Re-download Models" deletes the whole MODEL_FOLDER recursively. The README instructs users to place manually downloaded models there (README.md:44), so a user who manually populated that folder loses it without any confirmation prompt. The path is fixed inside the extension directory, so the blast radius is limited, but the deletion is still unannounced. Ask for confirmation before deleting, and move models to a user-chosen data directory instead of the extension install directory (which is replaced on extension update).
- [`OpenMAPT1AutoParcellation/OpenMAPT1AutoParcellation.py:207-210`](https://github.com/niyaziacer/SlicerOpenMAPT1Auto/blob/0a3c1aa519880a4c8f3d6110810b88829f9c615b/OpenMAPT1AutoParcellation/OpenMAPT1AutoParcellation.py#L207-L210): `slicer.util.pip_install` forwards its arguments to pip; `"gdown --upgrade"` is a single argument and is not a valid requirement specifier, so pip will error out (caught by the broad except and only logged). Even if it worked, it would silently upgrade a package in Slicer's environment during a download action. Use `slicer.util.pip_install("gdown")` (or `pip_install("--upgrade", "gdown")` if an upgrade is really needed) and only after user confirmation.
- [`OpenMAPT1AutoParcellation/OpenMAPT1AutoParcellationLib/utils/postprocessing.py:7-9`](https://github.com/niyaziacer/SlicerOpenMAPT1Auto/blob/0a3c1aa519880a4c8f3d6110810b88829f9c615b/OpenMAPT1AutoParcellation/OpenMAPT1AutoParcellationLib/utils/postprocessing.py#L7-L9): The lookup table is deserialized with `pickle`, which can execute arbitrary code. The file is committed in the repository (7 KB binary) and cannot be audited by reading it, so any future replacement of that file — or a tampered build — becomes code execution inside Slicer. The data is a simple key→value mapping that needs no pickle. Store the mapping as JSON or .npz and load it with `json.load`/`numpy.load`, or at minimum document and hash-pin the pickle.
- [`OpenMAPT1Auto.json:26-32`](https://github.com/niyaziacer/SlicerOpenMAPT1Auto/blob/0a3c1aa519880a4c8f3d6110810b88829f9c615b/OpenMAPT1Auto.json#L26-L32): The catalog entry pins `scm_revision: "main"`, but the extension's own metadata, README links and CMake icon/screenshot URLs all use `master`. If the default branch is `main`, the raw.githubusercontent `master` URLs for the icon and screenshots 404, and the metadata is misleading. The root `OpenMAPT1Auto.json` is also not a file the Slicer extension build consumes. Align all branch references with the branch actually used by the index, and remove or relocate the non-standard root JSON if it is not used by the build.
- [`OpenMAPT1AutoParcellation/OpenMAPT1AutoParcellation.py:312-316`](https://github.com/niyaziacer/SlicerOpenMAPT1Auto/blob/0a3c1aa519880a4c8f3d6110810b88829f9c615b/OpenMAPT1AutoParcellation/OpenMAPT1AutoParcellation.py#L312-L316): runPipeline() runs all inference synchronously in the Qt GUI thread. The README says CPU runs take 15-45 minutes. The UI freezes apart from processEvents calls in logMessage, and there is no cancel button. Run inference in a worker thread or as a separate process, and show progress with a cancel option.
- [`OpenMAPT1AutoParcellation/CMakeLists.txt:12-17`](https://github.com/niyaziacer/SlicerOpenMAPT1Auto/blob/0a3c1aa519880a4c8f3d6110810b88829f9c615b/OpenMAPT1AutoParcellation/CMakeLists.txt#L12-L17): Only the generic load test is built; there is no test of the pipeline, no sample T1 volume, and no tutorial beyond the README steps. For a deep-learning tool producing anatomical measurements there is no statement of validation/accuracy, no model version or checksum, and no explicit research-use-only / not-for-clinical-diagnosis disclaimer (only the non-commercial note). Add a small sample dataset and a smoke test, document the model version/checksum and any published validation, and add an explicit research-use-only disclaimer in the module UI and README.
- [`OpenMAPT1AutoParcellation/OpenMAPT1AutoParcellation.py:22-26`](https://github.com/niyaziacer/SlicerOpenMAPT1Auto/blob/0a3c1aa519880a4c8f3d6110810b88829f9c615b/OpenMAPT1AutoParcellation/OpenMAPT1AutoParcellation.py#L22-L26): `required` contains `"gdown>=4.6.0"` (line 17). `importlib.import_module("gdown>=4.6.0")` can never succeed because that is not a module name, so the ImportError branch runs `pip_install("gdown>=4.6.0")` on every Slicer start, adding network traffic and startup delay even when gdown is already installed. `torchvision` and `tqdm` are installed but never imported anywhere in the extension. Separate module names from requirement specifiers (dict of name -> spec), and drop unused packages.
