- [`VolBrainVolumeCalculator/VolBrainVolumeCalculator.py:594-603`](https://github.com/niyaziacer/SlicerVolBrain/blob/4910a7ff3f6b20fa9e1f07c04f334616e82ffb6d/VolBrainVolumeCalculator/VolBrainVolumeCalculator.py#L594-L603): calculateVolumes runs np.sum(array == label) once per label on the full volume on the GUI thread, which is slow for large volumes and freezes Slicer with no progress updates inside the loop. Use np.bincount for counts in one pass, guard the empty case, and report errors to the user via the status label or a message box.
