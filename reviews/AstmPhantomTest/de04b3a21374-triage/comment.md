Suggestions for a later update:

- [`AstmPhantomTest/AstmPhantomTest.py:124`](https://github.com/Atracsys/SlicerAstmPhantomTest/blob/de04b3a2137407f38eff5f468a1331975a364b5e/AstmPhantomTest/AstmPhantomTest.py#L124): The whole widget setup (logic creation, all signal connections, file selectors, OpenIGTLink connector) is inside this if-block. If the user presses Cancel in the folder dialog that pops up every time the module is opened, the module shows an empty panel with no explanation and no way to recover except reopening the module; any later callback that assumes self.logic exists would fail. Ask for the folder lazily (e.g. when the session starts) or show an explicit message and a button to re-open the dialog when it is cancelled.
- [`AstmPhantomTest/AstmPhantomTest.py:73`](https://github.com/Atracsys/SlicerAstmPhantomTest/blob/de04b3a2137407f38eff5f468a1331975a364b5e/AstmPhantomTest/AstmPhantomTest.py#L73): These global settings are applied when the module is opened and never restored in exit()/cleanup(). After a user opens the module once, the Slicer main window cannot be resized beyond 1920x1080 and every view node in the scene has axis labels and the orientation box turned off (lines 105-108), which affects all other modules for the rest of the session. The custom layout 401 is also registered and activated globally. Save and restore the previous window maximum size and view-node settings in exit()/cleanup(), or avoid changing them at all.
- [`AstmPhantomTest/AstmPhantomTest.py:129-131`](https://github.com/Atracsys/SlicerAstmPhantomTest/blob/de04b3a2137407f38eff5f468a1331975a364b5e/AstmPhantomTest/AstmPhantomTest.py#L129-L131): Each time the module is opened a new handler is attached to the root logger and never detached, so log lines are duplicated N times after N module opens, file handles accumulate, and the handler keeps writing to a folder the user may have since deleted. Store the handler on the widget and remove/close it in cleanup().
- [`AstmPhantomTest/AstmPhantomTestClasses/Phantom.py:55-59`](https://github.com/Atracsys/SlicerAstmPhantomTest/blob/de04b3a2137407f38eff5f468a1331975a364b5e/AstmPhantomTest/AstmPhantomTestClasses/Phantom.py#L55-L59): modelId is only created inside readGroundTruthFile when a MODEL line is present (Phantom.py:93-94); WorkingVolume.py:172 has the same pattern. A user-supplied ground-truth or working-volume file without MODEL therefore raises AttributeError instead of showing the intended error dialog, and the module state is left half-initialized. Initialize self.modelId = None in __init__ of both classes.
