- [`ABLTemporalBoneSegmentationModule/ABLTemporalBoneSegmentationModule.py:23-26`](https://github.com/Auditory-Biophysics-Lab/Slicer-ABLTemporalBoneSegmentation/blob/227bc565ddec65509bac6dcbbddd6c02e718eaeb/ABLTemporalBoneSegmentationModule/ABLTemporalBoneSegmentationModule.py#L23-L26): When Slicer starts up and imports scripted modules, `ABLTemporalBoneSegmentationModule.py` runs `slicer.util.pip_install("ablinfer")` at top-level module import time without user confirmation. Smaller suggestions:

- [`ABLTemporalBoneSegmentationModule/ABLTemporalBoneSegmentationModule.py:1038-1039`](https://github.com/Auditory-Biophysics-Lab/Slicer-ABLTemporalBoneSegmentation/blob/227bc565ddec65509bac6dcbbddd6c02e718eaeb/ABLTemporalBoneSegmentationModule/ABLTemporalBoneSegmentationModule.py#L1038-L1039): If the user cancels the `QFileDialog.getExistingDirectory` dialog, `target` is an empty string `""`. `export_for_cardinalsim` then calls `os.path.abspath("")`, which resolves to the current working directory, and proceeds to write files and `shutil.rmtree(os.path.join(directory, volume.GetName() + "_dicom"))` in the current working directory instead of aborting. Check `if not target: return` before calling `export_for_cardinalsim`.
- [`ABLTemporalBoneSegmentationModule/ABLTemporalBoneSegmentationModule.py:932-938`](https://github.com/Auditory-Biophysics-Lab/Slicer-ABLTemporalBoneSegmentation/blob/227bc565ddec65509bac6dcbbddd6c02e718eaeb/ABLTemporalBoneSegmentationModule/ABLTemporalBoneSegmentationModule.py#L932-L938): When using remote inference, TLS certificate verification is unconditionally disabled (`s.verify = False`), and the user's password is saved in plaintext in Slicer's `QSettings` (`ablinfer_server_password`), while `self.inferServerPassword` is also a plain `qt.QLineEdit()` without `Password` echo mode. Disabling TLS verification exposes credentials and medical image payloads to man-in-the-middle interception, and storing passwords in plaintext settings exposes them on disk. Enable TLS verification by default (or provide an explicit opt-in checkbox for self-signed certificates), set `self.inferServerPassword.setEchoMode(qt.QLineEdit.Password)`, and avoid persisting plaintext passwords in `QSettings`.
- [`ABLTemporalBoneSegmentationModule/ABLTemporalBoneSegmentationModule.py:1418-1425`](https://github.com/Auditory-Biophysics-Lab/Slicer-ABLTemporalBoneSegmentation/blob/227bc565ddec65509bac6dcbbddd6c02e718eaeb/ABLTemporalBoneSegmentationModule/ABLTemporalBoneSegmentationModule.py#L1418-L1425): The UI permits selection of any segmentation, and the exporter converts its segments in their current order before assigning these fixed names to label values. A reordered or different segmentation can therefore be exported under incorrect anatomical filenames without warning. Map labels using verified segment names or IDs, reject unexpected or missing structures, and test reordered segments.
- [`ABLTemporalBoneSegmentationModule/ABLTemporalBoneSegmentationModule.py:935-938`](https://github.com/Auditory-Biophysics-Lab/Slicer-ABLTemporalBoneSegmentation/blob/227bc565ddec65509bac6dcbbddd6c02e718eaeb/ABLTemporalBoneSegmentationModule/ABLTemporalBoneSegmentationModule.py#L935-L938): Remote server passwords are stored as ordinary Slicer settings and are restored into a normal QLineEdit at lines 357–364, exposing them to anyone who can read the settings or see the screen. Mask the password field and avoid persisting credentials, or use an operating-system credential store with explicit consent.
- [`ABLTemporalBoneSegmentationModule/ABLTemporalBoneSegmentationModule.py:37`](https://github.com/Auditory-Biophysics-Lab/Slicer-ABLTemporalBoneSegmentation/blob/227bc565ddec65509bac6dcbbddd6c02e718eaeb/ABLTemporalBoneSegmentationModule/ABLTemporalBoneSegmentationModule.py#L37): Calling `urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)` at the top level of the module globally silences TLS certificate verification warnings across the entire Slicer Python process at startup, affecting all other modules and extensions. Avoid globally disabling `InsecureRequestWarning` at module import time; scope warning suppression locally if unverified HTTPS requests are explicitly requested by the user.
- [`IntraSampleRegistration/IntraSampleRegistration.py:99-101`](https://github.com/Auditory-Biophysics-Lab/Slicer-ABLTemporalBoneSegmentation/blob/227bc565ddec65509bac6dcbbddd6c02e718eaeb/IntraSampleRegistration/IntraSampleRegistration.py#L99-L101): Both `IntraSampleRegistrationWidget` (line 100) and `ABLTemporalBoneSegmentationModuleWidget` (line 151) instantiate `Elastix.ElastixLogic()` in the class body rather than inside `__init__` or `setup()`. This executes `ElastixLogic()` at module import time during Slicer startup, slowing startup and risking initialization order issues if `Elastix` is not yet loaded. Instantiate `Elastix.ElastixLogic()` inside `__init__` or lazily when registration is run rather than at class definition time.
