- [`ClassAnnotation/ClassAnnotationLib/ClassAnnotationUtils.py:42-44`](https://github.com/lorenaromeo/SlicerClassAnnotation/blob/f2db4d2b6b2a626a7318aa50359fb01cb2538a1d/ClassAnnotation/ClassAnnotationLib/ClassAnnotationUtils.py#L42-L44): For flat cases named patient1.nrrd and patient10.nrrd, the original-file lookup for patient1 includes both. Match the exact extracted patient ID consistently with getPatientFilesForReview, and test IDs that share prefixes.
- [`ClassAnnotation/ClassAnnotation.py:2888`](https://github.com/lorenaromeo/SlicerClassAnnotation/blob/f2db4d2b6b2a626a7318aa50359fb01cb2538a1d/ClassAnnotation/ClassAnnotation.py#L2888): Feature names are editable and generation calls migrateRenamedFeaturesBeforeGenerate, which invokes this function for the new name. Renaming a feature to `..` makes featureDir resolve to the parent output directory; rmtree can recursively remove its CSVs, class folders, and any unrelated user files there, even if the final directory removal fails. Reject dot components and path separators, resolve and verify containment under a dedicated managed directory, and avoid recursively deleting paths based on user-provided names.
- [`ClassAnnotation/ClassAnnotation.py:446`](https://github.com/lorenaromeo/SlicerClassAnnotation/blob/f2db4d2b6b2a626a7318aa50359fb01cb2538a1d/ClassAnnotation/ClassAnnotation.py#L446): After assigning a single-label class, the module clears the entire MRML scene, not just its own loaded patient nodes. Users who added or edited unrelated unsaved nodes after the initial dataset-load confirmation lose that work without a new warning; similar clears occur during mode changes and review. Remove only nodes created by this module, or explicitly confirm and save before any whole-scene clear.
- [`ClassAnnotation/ClassAnnotation.py:3718-3723`](https://github.com/lorenaromeo/SlicerClassAnnotation/blob/f2db4d2b6b2a626a7318aa50359fb01cb2538a1d/ClassAnnotation/ClassAnnotation.py#L3718-L3723): Every single-label save invokes this cleanup on the selected base's existing output folder. An unrelated directory such as output/class123_backup that is not an active class matches the regex and is silently removed recursively, without checking ownership or asking the user. Use a dedicated newly created managed output directory or an explicit ownership manifest; never recursively delete unverified existing folders.
- [`ClassAnnotation/ClassAnnotationLib/ClassAnnotationUtils.py:31-33`](https://github.com/lorenaromeo/SlicerClassAnnotation/blob/f2db4d2b6b2a626a7318aa50359fb01cb2538a1d/ClassAnnotation/ClassAnnotationLib/ClassAnnotationUtils.py#L31-L33): If a user selects a dataset under a parent such as /data/output-study, every walked root contains `output`, so no originals are found for copying or hashing even though the images can be displayed and labeled.
