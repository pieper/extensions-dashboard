Suggestions for a later update:

- [`GyroGuide/GyroGuide.py:611-617`](https://github.com/lpfang/GyroGuide/blob/14766ab3b012c28f5ef0657395256e15b9304073/GyroGuide/GyroGuide.py#L611-L617): If any selected node has zero points the constructor `return`s (lines 545, 569, 595) leaving `self.position` short, so the following indexing raises IndexError/AttributeError; likewise markers nodes with fewer than five points make `self.position[0][3] - self.position[0][4]` (line 617) fail. The UI enables Calculate for any node with a valid type, so these exceptions reach the user as raw tracebacks. Validate point counts (>=5 markers, >=1 target, >=1 entry, distinct points, non-zero-length vectors) and report a clear message via slicer.util.errorDisplay instead of continuing.
- [`GyroGuide/GyroGuide.py:405`](https://github.com/lpfang/GyroGuide/blob/14766ab3b012c28f5ef0657395256e15b9304073/GyroGuide/GyroGuide.py#L405): The else branch is inside the loop, so for every connector node not named 'Send-Data' a new node is created and added; with N existing connectors the scene accumulates extra 'Send-Data' nodes and only the last one is used. Also, `vtkMRMLIGTLConnectorNode` is used without checking that the OpenIGTLink extension is installed. Look the node up once outside the loop (e.g. via GetFirstNodeByName) and create it only if absent; guard for a missing vtkMRMLIGTLConnectorNode class.
- [`GyroGuide/CMakeLists.txt:21-28`](https://github.com/lpfang/GyroGuide/blob/14766ab3b012c28f5ef0657395256e15b9304073/GyroGuide/CMakeLists.txt#L21-L28): GyroGuide.py defines no unittest.TestCase subclass, so the registered ctest has nothing to run, and GyroGuide/Testing/Python/CMakeLists.txt only contains a commented-out line, leaving the extension without any automated test at tier 3. Add a real ScriptedLoadableModuleTest (or the standard ModuleTest.py) and register it, so the extension has a passing smoke test.
- [`GyroGuide/GyroGuide.py:1`](https://github.com/lpfang/GyroGuide/blob/14766ab3b012c28f5ef0657395256e15b9304073/GyroGuide/GyroGuide.py#L1): The module uses plain classes with 'from __main__ import' rather than ScriptedLoadableModule, which is fragile on current Slicer. The catalog pins scm_revision to the branch 'master', so the built code can change without a catalog update. Port to ScriptedLoadableModule and pin scm_revision to a specific commit hash.
- [`GyroGuide/Testing/Python/CMakeLists.txt:2`](https://github.com/lpfang/GyroGuide/blob/14766ab3b012c28f5ef0657395256e15b9304073/GyroGuide/Testing/Python/CMakeLists.txt#L2): WITH_GENERIC_TESTS is set, but the module has no test class and the Testing registration is commented out. The README is one sentence, and no sample data or tutorial is included, so maintainers and users cannot verify the geometry. Add a unit test with synthetic fiducials and expected angles and depth, and expand the README with usage and a disclaimer.
- [`GyroGuide/GyroGuide.py:427-433`](https://github.com/lpfang/GyroGuide/blob/14766ab3b012c28f5ef0657395256e15b9304073/GyroGuide/GyroGuide.py#L427-L433): The result of Start() is never checked and no error is shown, so if the device is unreachable the transform is registered and then the connector is stopped without the user knowing nothing was delivered; a non-numeric port raises an uncaught ValueError from `int(...)` in the GUI click handler. Validate the port, check the Start() return value and surface connection failures with slicer.util.errorDisplay / warning; disable Send until a connection succeeds.
