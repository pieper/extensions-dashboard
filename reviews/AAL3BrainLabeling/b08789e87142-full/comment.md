- [`AAL3BrainLabeling.py:297-304`](https://github.com/niyaziacer/SlicerAAL3BrainLabeling/blob/b08789e87142603744cc02512c79a9a8f480a74b/AAL3BrainLabeling.py#L297-L304): `volumeStatistics` computes statistics via `SegmentStatisticsLogic` using default parameters, and `connectome()` then calls `self.getCentroid(stats, sid)` which searches for `'centroid'` in the statistics keys (`for k in stats.keys(): if len(k) == 2 and k[0] == sid and 'centroid' in k[1].lower(): return stats[k]`). In Slicer's `LabelmapSegmentStatisticsPlugin`, `centroid_ras` is NOT enabled by default (`centroid_ras` must be explicitly enabled via `logic.getParameterNode().SetParameter("LabelmapSegmentStatisticsPlugin.centroid_ras.enabled", str(True))`). Because it is not enabled, `getCentroid` always falls back to `(0.0, 0.0, 0.0)` for every region, causing the exported `*_Connectome_Matrix.csv` to be an all-zero matrix. Enable the centroid measurement before calling `logic.computeStatistics()`:
`logic.getParameterNode().SetParameter("LabelmapSegmentStatisticsPlugin.centroid_ras.enabled", str(True))`
- [`AAL3BrainLabeling.py:312-316`](https://github.com/niyaziacer/SlicerAAL3BrainLabeling/blob/b08789e87142603744cc02512c79a9a8f480a74b/AAL3BrainLabeling.py#L312-L316): The statistics setup does not explicitly enable a centroid measurement. If the active SegmentStatistics configuration does not provide it, the pipeline substitutes the origin and exports zero or otherwise incorrect distances as successful results, with no warning. Explicitly enable the intended centroid measurement, verify each region has a valid centroid, and report missing measurements instead of substituting coordinates.
- [`AAL3BrainLabeling.py:320-323`](https://github.com/niyaziacer/SlicerAAL3BrainLabeling/blob/b08789e87142603744cc02512c79a9a8f480a74b/AAL3BrainLabeling.py#L320-L323): Rerunning an analysis with the same volume name in the chosen results folder silently truncates the previous morphometry CSV; the matrix export similarly overwrites its prior file. MRML node names can also contain absolute paths or parent-directory components, allowing a supplied or renamed volume to direct the generated filename outside the chosen folder and overwrite a matching file there. Generate safe basename-only output names, check containment within the selected directory, and use unique outputs or explicit overwrite confirmation for both exports.
