- [`AFTSegmenter/AFTSegmenter.py:348`](https://github.com/CSIM-Toolkits/Slicer-LesionSpotlightExtension/blob/8bb4e99ef1cbe37ab8402f7feda5cad39fb31380/AFTSegmenter/AFTSegmenter.py#L348): AFTSegmenter and LSContrastEnhancer read their atlas data from the LSSegmenter module directory via `slicer.modules.lssegmenter.path`, but both declare `self.parent.dependencies = []` (AFTSegmenter.py line 34, LSContrastEnhancer.py line 39). If LSSegmenter has not been instantiated in the session, `slicer.modules.lssegmenter` raises AttributeError and the module cannot run; the dependency is also invisible to the module manager. Declare `self.parent.dependencies = ["LSSegmenter"]` in both modules, or move the shared atlas data to a location owned by each module.
- [`LSSegmenter/LSSegmenter.py:497-500`](https://github.com/CSIM-Toolkits/Slicer-LesionSpotlightExtension/blob/8bb4e99ef1cbe37ab8402f7feda5cad39fb31380/LSSegmenter/LSSegmenter.py#L497-L500): Every `slicer.cli.run(...)` call in LSSegmenter.py (364, 380, 421, 441, 454, 473, 484, 497), AFTSegmenter.py (334, 344, 388, 411, 429, 445) and LSContrastEnhancer.py (386, 400, 440, 458, 476, 486) discards the returned CLI node and never inspects its status. If a step fails (missing template, bad geometry, registration failure) the pipeline continues with empty or stale volumes and finally prints 'Processing completed', so the user gets a silently wrong or empty lesion map instead of an error. Capture the CLI node, check its status/completed state after each step, and abort with `slicer.util.errorDisplay` on failure.
- [`README.md:33`](https://github.com/CSIM-Toolkits/Slicer-LesionSpotlightExtension/blob/8bb4e99ef1cbe37ab8402f7feda5cad39fb31380/README.md#L33): The extension code is Apache-2.0 (LICENSE, README line 33) and the C++ sources carry matching Apache headers, which permits distribution. The bundled MNI152 atlas volumes under LSSegmenter/Resources/LSSegmenter-Data/ have no stated license or attribution in the repository, so their redistribution terms are unverified. Document the origin and license of the bundled MNI152 templates (e.g. MNI/McConnell Brain Imaging Centre terms) in the README or a NOTICE file.

The bundled MNI152 template (MNI152_T1_1mm*.nii.gz) and white-matter label files (MNI152_T1_WhiteMatter*.nii.gz, MNI152_T1_1mm_brain_tissues.nii.gz) come from the MNI/McConnell Brain Imaging Centre and similar sources whose terms are not reproduced here. - [`LSSegmenter/LSSegmenter.py:421`](https://github.com/CSIM-Toolkits/Slicer-LesionSpotlightExtension/blob/8bb4e99ef1cbe37ab8402f7feda5cad39fb31380/LSSegmenter/LSSegmenter.py#L421): The whole pipeline (N4 bias correction, anisotropic diffusion, BRAINSFit registration, up to 10 enhancement iterations, resampling) runs synchronously from the widget's `onApplyButton` with `wait_for_completion=True` and no progress dialog or event processing. Slicer's GUI is frozen for the entire run (minutes on typical T2-FLAIR volumes), which looks like a hang and prevents cancellation. Drive the CLI steps without `wait_for_completion` and with a progress dialog/status observer so the GUI stays responsive and the run can be cancelled.
- [`CMakeLists.txt:11`](https://github.com/CSIM-Toolkits/Slicer-LesionSpotlightExtension/blob/8bb4e99ef1cbe37ab8402f7feda5cad39fb31380/CMakeLists.txt#L11): The extension targets MS lesion segmentation on T2-FLAIR MRI and cites peer-reviewed methods (Senra Filho 2018, Cabezas 2014), with a ReadTheDocs site and screenshots. However there is no clinical-use disclaimer, no statement of validation performance/limitations, and the atlas templates (MNI152) bundled in the repository have no provenance or license statement in the README or docs, which matters for a research segmentation tool. Add a research-use-only disclaimer, a short validation summary, and the source/license of the bundled MNI152 templates to the README and docs.
- [`LSSegmenter/LSSegmenter.py:39`](https://github.com/CSIM-Toolkits/Slicer-LesionSpotlightExtension/blob/8bb4e99ef1cbe37ab8402f7feda5cad39fb31380/LSSegmenter/LSSegmenter.py#L39): The extension's modules call `slicer.modules.n4itkbiasfieldcorrection`, `aadimagefilter`, `brainsfit`, `brainsresample`, `resamplescalarvectordwivolume`, `logisticcontrastenhancement`, `weightedenhancementimagefilter`, `lesionmaprefinement` and `automaticflairthreshold`, but no module declares dependencies, so the module manager cannot warn the user when a required CLI (e.g. BRAINSFit from SlicerElastix/BRAINSTools) is unavailable; the failure then surfaces as an AttributeError inside the pipeline. List the required CLI modules in `self.parent.dependencies` so missing dependencies are reported by Slicer.
- [`LSSegmenter/LSSegmenter.py:504`](https://github.com/CSIM-Toolkits/Slicer-LesionSpotlightExtension/blob/8bb4e99ef1cbe37ab8402f7feda5cad39fb31380/LSSegmenter/LSSegmenter.py#L504): The temporary nodes are only removed on the success path at the end of `run()`. Any exception in between (e.g. a failed load returning None, or a CLI error) leaves `inputFLAIRVolume_tmp`, `lesionUpdate`, the registration transform and the atlas label nodes in the scene, cluttering the user's scene with unnamed nodes on every failed attempt. Wrap the pipeline in try/finally and remove the temporary nodes in the finally block.
