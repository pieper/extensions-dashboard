Suggestions for a later update:

- [`KonfAI/KonfAILib/widgets/app_template.py:198-202`](https://github.com/vboussot/SlicerKonfAI/blob/67776b1a948593e52745d21ae718b86bc20cce13/KonfAI/KonfAILib/widgets/app_template.py#L198-L202): get_remote_server splits the `RemoteServer` parameter on '|' and evaluates the fourth field to a bool. Today only the module writes that parameter, so this is not an injection path from outside, but a saved scene file can carry arbitrary parameter strings, and a crafted .mrs scene would execute code when the module runs a job with a remote server set. Replace `eval(ok)` with `ok == "True"`.
- [`KonfAI/KonfAILib/widgets/panels/selection.py:444-449`](https://github.com/vboussot/SlicerKonfAI/blob/67776b1a948593e52745d21ae718b86bc20cce13/KonfAI/KonfAILib/widgets/panels/selection.py#L444-L449): The refresh/download action builds a Python source string with textwrap.dedent f-string interpolation of `app._repo_id` and `app._app_name` and executes it with `sys.executable -c`. `selected_files` is inserted with !r (safe), but the repo id and app name are inserted verbatim inside double quotes, so a quote character in either value would break out of the literal and inject code into the executed script. The values come from app objects the user selected, so this is a robustness/defense-in-depth issue rather than an established external attack path. Insert these values with `{app._repo_id!r}` / `{app._app_name!r}`, or run the download in-process / from a real script file with arguments instead of -c.
- [`KonfAI/CMakeLists.txt:40-45`](https://github.com/vboussot/SlicerKonfAI/blob/67776b1a948593e52745d21ae718b86bc20cce13/KonfAI/CMakeLists.txt#L40-L45): `core_widget.py` loads `Icons/studio.png` and `helpers.app_task_icon` loads `Icons/task_segmentation.png` / `task_registration.png` / `task_synthesis.png` / `task_app.png`, but MODULE_PYTHON_RESOURCES only lists download.png, folder.png, gear.png, KonfAI.png and refresh.png. In a package built by the extension factory those files are absent, so the Studio button and the app-selector glyphs render as empty icons for end users, even though they exist in the source tree (10 files under Resources/Icons). Add Resources/Icons/studio.png and Resources/Icons/task_*.png to MODULE_PYTHON_RESOURCES (or list all icons in Resources/Icons).
- [`KonfAI/KonfAILib/widgets/core_widget.py:581-594`](https://github.com/vboussot/SlicerKonfAI/blob/67776b1a948593e52745d21ae718b86bc20cce13/KonfAI/KonfAILib/widgets/core_widget.py#L581-L594): populate_apps() lists Hugging Face repositories and builds app objects on the GUI thread (using processEvents feedback), `_update_ram`/`_update_vram` issue an HTTP GET to the remote server every 3 s while the module is visible, and `get_latest_pypi_version` blocks up to 5 s on module entry. With a slow or unreachable server the module panel freezes during those calls. Move the remote polling and repository listing to a worker thread or a QProcess/QtNetwork request and update the widgets from the main thread.
- [`KonfAI/KonfAILib/widgets/panels/selection.py:375-378`](https://github.com/vboussot/SlicerKonfAI/blob/67776b1a948593e52745d21ae718b86bc20cce13/KonfAI/KonfAILib/widgets/panels/selection.py#L375-L378): When the user ticks 'Also delete the folder from disk' and confirms the warning dialog, `shutil.rmtree(app.get_name())` deletes whatever path the local app repository reports. The path is not validated against the app repository root and may be relative, so it resolves against Slicer's current working directory. The action is explicitly double-confirmed by the user, which limits the risk. Resolve the app directory from the repository object and refuse to delete unless it is inside the known KonfAI app repository/cache root.
- [`KonfAI/KonfAILib/logic/servers.py:84-87`](https://github.com/vboussot/SlicerKonfAI/blob/67776b1a948593e52745d21ae718b86bc20cce13/KonfAI/KonfAILib/logic/servers.py#L84-L87): cli_args() appends `--token <token>` to the konfai-apps argv. On shared multi-user machines any local user can read the full command line of the child process (e.g. via ps), exposing the remote GPU server credentials the extension stores encrypted in the keyring. The token is only sent to a server the user configured, so the exposure is local and modest. Pass the token through an environment variable or a 0600 temporary config/credential file rather than argv.
- [`KonfAI/KonfAILib/logic/dependencies.py:153-156`](https://github.com/vboussot/SlicerKonfAI/blob/67776b1a948593e52745d21ae718b86bc20cce13/KonfAI/KonfAILib/logic/dependencies.py#L153-L156): On the 'reinstall KonfAI-apps' branch the extension installs `tqdm numpy ruamel.yaml psutil tensorboard lxml h5py nvidia-ml-py requests huggingface_hub` unpinned in one pip call. If any package is missing (e.g. on a Slicer build where a dependency was not satisfied) pip resolves and installs the latest release, including its transitive requirements, which can upgrade numpy/requests under Slicer's feet. This runs only after user consent, which limits the impact. Let konfai-apps' own metadata declare these dependencies (install it without --no-deps), or constrain them so Slicer-bundled packages such as numpy and requests are never upgraded.
- [`KonfAI/KonfAILib/widgets/app_template.py:108`](https://github.com/vboussot/SlicerKonfAI/blob/67776b1a948593e52745d21ae718b86bc20cce13/KonfAI/KonfAILib/widgets/app_template.py#L108): In on_run_button, any exception raised while preparing or starting the run is only `print(e)`ed and the running flag is reset; the user sees the log/progress stop but no error message. For instance a missing `konfai` module or a broken app manifest leaves the user with a silently cancelled operation. Also report the exception in the log panel and via slicer.util.errorDisplay (with details/traceback).
