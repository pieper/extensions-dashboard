Suggestions for a later update:

- [`AblationPlanner/AblationPlanner.py:298-302`](https://github.com/naterex23/SlicerAblationPlanner/blob/5b9622a808096cb2d1a7b14410c8b50b1b6f29a3/AblationPlanner/AblationPlanner.py#L298-L302): Pressing Place Markup Line removes every line markup, including pre-existing measurements and annotations belonging to the user or other modules. The endpoint drag handler also calls onLineButton, so routine probe adjustment can silently destroy unsaved scene data without confirmation. Track only lines created by this module using node references or a dedicated attribute, and update or remove only those lines.
- [`AblationPlanner/AblationPlanner.py:595`](https://github.com/naterex23/SlicerAblationPlanner/blob/5b9622a808096cb2d1a7b14410c8b50b1b6f29a3/AblationPlanner/AblationPlanner.py#L595): The color button replaces the model's Signed distance values with bin numbers rather than creating a separate display scalar. Revert iterates only to len(originalColorArray)-1, while the snapshot itself omits the final value, so at least one modified value is never restored; the original values are also kept only in widget memory. Subsequent use or saving of the model can therefore retain incorrect distance data. Keep Signed unchanged, create a separate color-bin array, and test the full apply/revert and scene-reload workflow.
- [`AblationPlanner/AblationPlanner.py:747-752`](https://github.com/naterex23/SlicerAblationPlanner/blob/5b9622a808096cb2d1a7b14410c8b50b1b6f29a3/AblationPlanner/AblationPlanner.py#L747-L752): When a probe's endpoints are aligned or anti-aligned with the reference direction [0,0,-1], the cross product is zero and the rotation formula divides by zero. Probe placement can then fail or propagate non-finite transform values for an otherwise valid axis-aligned input. Handle parallel and antiparallel vectors explicitly, reject coincident endpoints, and test these cases.
- [`AblationPlanner/AblationPlanner.py:220-225`](https://github.com/naterex23/SlicerAblationPlanner/blob/5b9622a808096cb2d1a7b14410c8b50b1b6f29a3/AblationPlanner/AblationPlanner.py#L220-L225): In `setParameterNode`, `self.addObserver(self._parameterNode, ...)` is called before `self._parameterNode = inputParameterNode` is assigned. This re-observes the old parameter node instead of observing the newly set `inputParameterNode`, and when `self._parameterNode` starts as `None`, the new parameter node is never observed at all. Assign `self._parameterNode = inputParameterNode` before checking `if self._parameterNode is not None:` to add the observer.
- [`AblationPlanner/AblationPlanner.py:793-798`](https://github.com/naterex23/SlicerAblationPlanner/blob/5b9622a808096cb2d1a7b14410c8b50b1b6f29a3/AblationPlanner/AblationPlanner.py#L793-L798): `convertSegmentToModel` assumes that the exported model's subject hierarchy item ID is `modelNode + 1`. Subject hierarchy item IDs are not guaranteed to be sequential integers (`modelNode + 1`), which can cause `shNode.GetItemDataNode(modelNode + 1)` to return `None` and raise an `AttributeError` on `folder.GetDisplayNode()`. Use `vtkIdList` with `shNode.GetItemChildren(modelNode, childIds)` to retrieve the exported child item ID reliably.
- [`AblationPlanner/AblationPlanner.py:689-693`](https://github.com/naterex23/SlicerAblationPlanner/blob/5b9622a808096cb2d1a7b14410c8b50b1b6f29a3/AblationPlanner/AblationPlanner.py#L689-L693): The loop iterates up to `GetNumberOfSegments() + 1`, so on the last iteration `i == GetNumberOfSegments()`, which is out of bounds for 0-indexed `GetNthSegmentID(i)` (returning an empty/None segment ID). Additionally, `convertSegmentsToSegment` instantiates a GUI widget (`slicer.qMRMLSegmentEditorWidget()`) inside the Logic class and leaks `vtkMRMLSegmentEditorNode` in the scene. Iterate over `range(1, segmentationNode.GetSegmentation().GetNumberOfSegments())` and remove the temporary `segmentEditorNode` from `slicer.mrmlScene` when finished.
- [`AblationPlanner/AblationPlanner.py:854-863`](https://github.com/naterex23/SlicerAblationPlanner/blob/5b9622a808096cb2d1a7b14410c8b50b1b6f29a3/AblationPlanner/AblationPlanner.py#L854-L863): The test reports success without loading data, placing probes, or checking computed margins, so it will not detect regressions in the main workflow. Add automated tests with known probe geometry, expected margins, and invalid input cases.
- [`AblationPlanner/AblationPlanner.py:249-251`](https://github.com/naterex23/SlicerAblationPlanner/blob/5b9622a808096cb2d1a7b14410c8b50b1b6f29a3/AblationPlanner/AblationPlanner.py#L249-L251): In `updateGUIFromParameterNode`, the node reference role has a stray `ƒ` character (`"NativeFiducialsƒ"`), whereas `self.nodeSelectors` (line 122) and `onTumorButton` (line 277) use `"NativeFiducials"`. Whenever `updateGUIFromParameterNode` runs, `nativeFiducialsSelector` will be reset to `None`. Change `"NativeFiducialsƒ"` to `"NativeFiducials"`.
